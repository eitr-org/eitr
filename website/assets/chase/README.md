# Side-gutter wolf sprite sheets

Original two-frame sheets generated with the built-in image tool using the
project's own drawn wolf as reference. Each sheet has equal-width cells:
closed mouth on the left, open mouth on the right. The body pose stays the same.
Genuine alpha transparency is preserved. `sync-art.mjs` exports the entire sheet
without separately trimming the frames, so their alignment remains consistent.

Generation brief: two identical full-body running-right wolves in the approved
flat drawn style, same scale/position, only the jaw changes. Sköll is orange and
ivory; Hati is slate blue/cyan and ivory. No landscape, celestial bodies, words,
rings or borders. Request a transparent background and two horizontal cells.

CSS rotates Sköll down and Hati up. These are jaw frames, not leg animations.
