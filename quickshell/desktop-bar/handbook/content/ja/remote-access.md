# リモートアクセス

Sunshine と Moonlight を使用するには 設定 > ストリーミング を開くか、同様の操作を行うために Walker > 設定 > デバイス > ストリーミング を開きます。ホスティングは有効にするまでオフになっています。今回のマイルストーンでは、サインイン済みでスリープしていない Eitr デスクトップを制御します。ヘッドレスでの使用、ログイン前のアクセス、Wake on LAN は今後の別の作業となります。画面共有中、この PC がロックされるとリモート画面にもロック画面が表示されます。接続しているすべてのユーザーにそれが表示され、パスワードを入力できるため、プライバシーが重要な場合は離席する前に共有を停止してください。

設定フォルダーにより設定操作がグループ化されています。ストリーミング > 共有セットアップ には、「共有のセットアップ」、「共有設定」、「ログイン時に開始」、「ログイン時の開始を無効化」、「詳細ステータス」、「共有セットアップの復元」が含まれます。日常的な共有操作（「共有を開始」、「共有を停止」、「デバイスのペアリング」、「共有ステータス」、「別のPCに接続」）は「ストリーミング」に直接配置されています。

「詳細ステータス」を開くと診断ターミナルが起動し、Esc を押すまで開いたままになります。

## Eitr上のSunshine

「このPCを共有」>「セットアップ」>「共有のセットアップ」を選択します。インストールには、リリースメインテナーがアップストリームソースからビルドした Eitr の署名付きネイティブ Sunshine パッケージが使用されます。初回クリック時に AUR ビルドが行われることはありません。Flatpak と AppImage には KMS キャプチャ機能がありません。既存の Sunshine 設定とペアリングされたデバイスは保持されます。同時に別の Sunshine インスタンスを実行しないでください。

完全な制御に関する警告を読み、KMS 画面キャプチャおよび仮想キーボード、マウス、コントローラーの入力を許可する場合にのみ `yes` と入力してください。セットアップにより、元の権限が `/var/lib/eitr/remote-access` に非公開で保存されます。uinput の udev ルールが追加され、起動時に uinput がロードされ、デスクトップユーザーにデバイスへのアクセス権が付与され、Sunshine に `cap_sys_admin+p` が付与されます。これらは強力な権限です。

「共有セットアップの復元」は共有を停止し、保存されたファイルとデバイス ACL を復元して、キャプチャ権限を削除します。セットアップによって uinput がロードされていた場合、復元処理によってそれもアンロードされます。別のアプリケーションがまだそれを使用している場合、復元処理は失敗を報告してログ（ジャーナル）を保持するため、そのアプリケーションを終了してから再試行できます。

「共有を開始」は、リモートデバイスに制御権を与える前に確認を求めます。ローカルの Web 設定は `https://localhost:47990` で開きます。初回使用時は、パスワードを設定するまでストリーミングはブロックされたままになります。ターミナルに戻って設定が完了したことを確認すると、管理者パスワードによってリモート制御が有効化されます。ローカルの自己署名証明書は、そのアドレスでのみ承認してください。

ペアリングを行う前に、Sunshine のユーザー名と強力なパスワードを設定してください。セットアップ内の「共有設定」からここに戻ることができます。「デバイスのペアリング」を開くと PIN 入力ページが表示されます。自分自身の Moonlight デバイスに表示された PIN のみを入力してください。ルーターの自動設定はオフのままにしてください。Eitr では `upnp=off` が強制されます。ルーターのポート転送は設定しないでください。

TCP 47984、47989、48010、および UDP 47998〜48000 は、直接接続されたプライベート LAN サブネットからのみ許可されます。TCP 47990 は、他のファイアウォールルールで許可されている場合であっても、この PC のみに制限されます。LAN のスコープは開始ごとに取得されるため、ネットワークを変更した後は共有を停止して再起動してください。信頼できるホームネットワークのみを使用してください。

「共有を停止」はログイン時の自動開始も無効化し、確立済みのストリームを含めストリーミングポートを閉じます。サービスに障害が発生した場合もポートは閉じられます。実行時に開放されたポートが再起動後に残ることはありません。初回起動以降は、「共有を開始」と「共有を停止」が確認やパスワードなしですぐに切り替わります。「ログイン時に開始」は任意であり、「ストリーミング」パネルまたはメニューからすぐに切り替えることができます。「ログイン時の開始を無効化」を選択すると、手動での共有が維持されます。

「共有ステータス」にはサービスのエラーが表示されます。

Sunshine パッケージの更新によって実行ファイルが置き換えられると、キャプチャケイパビリティがクリアされます。その後、更新処理によって共有をセットアップしたアカウントにそれが再び付与されます。それでも共有を開始できない場合は、「ストリーミング」の切り替えトグルに理由が表示されます。再度「共有のセットアップ」を実行するか、初回セットアップ後であれば一度サインアウトして再度サインインしてください。元の復元レコードは保持されます。

Sunshine は、root または共有用アカウントとしてのみ KMS ケイパビリティを伴って実行されます。セットアップにより実行ファイルが `root:eitr-sharing`、パーミッション `0750` に設定され、ユーザーのアカウントがそのシステムグループに追加されます。ユーザーサービスが新しいグループを認識できるように、共有を開始する前に一度サインアウトして再度サインインしてください。セットアップは実行中の共有プロセスをそのままアクティブにしておくため、次回ログイン前の再起動は失敗する可能性があります。

「共有を停止」してもセットアップ時の権限は保持されます。「共有セットアップの復元」は、グループの所属とすべてのバイナリケイパビリティを削除し、古いセットアップレコードを復元する場合も含め、実行ファイルを `root:root`、パーミッション `0755` に戻します。パッケージの更新後、「共有のセットアップ」はケイパビリティを再付与する前に所有者とパーミッションを修復します。

## Mac上のMoonlight

[Moonlight プロジェクト](https://moonlight-stream.org/) から Moonlight をインストールします。最初のテストでは、Eitr と Mac を同じホームネットワークに接続してください。自動検出で見つからない場合は、手動で Eitr の LAN アドレスを追加します。PC を選択し、その PIN を確認してから、Eitr で「デバイスのペアリング」を使用します。「Desktop」を選択して、アプリケーションやゲームを操作します。Sunshine の設定でキャプチャするディスプレイを選択します。各モニターを個別に確認してください。「ゲーム」>「Moonlight」および「別のPCに接続」は、逆方向に接続するための Eitr クライアントをインストールまたは開きます。クリーンインストールにはこれらのアプリが含まれていますが、明示的に有効にするまで共有はオフのままです。

Mac からの SUPER ショートカット: Moonlight の設定で、**Capture system keyboard shortcuts**（全画面時または常に）をオンにします。これにより、Moonlight は Mac の Command キーを SUPER として送信するようになります。そうしない場合、Command ショートカットは Mac 側で処理されます。セッション中に Ctrl+Alt+Shift+K を押すと、キャプチャのオン/オフを切り替えることができます。

## 検証済みの内容

自動テストではモックが使用されています。実機のデスクトップ（1台および2台のモニター構成）と Moonlight を実行する MacBook において、セットアップ、共有開始、アドレスによるペアリング、映像、キーボード、マウス、オーディオ、ロック画面（Mac からのロック解除）、ログイン時の自動開始、「共有を停止」、および「共有セットアップの復元」が、ホームネットワーク上および VPN 経由の外出先から検証されています。コントローラー、その他の GPU、その他のクライアントはテストされていません。

「ストリーミング」は「デバイス」内の「接続」の隣に配置されています。Sunshine には共有ステータス、セットアップ、開始/停止、ログイン時に開始、ペアリング、設定、診断、セットアップの復元が表示されます。Moonlight にはインストール状況とインストール/起動ボタンが表示されます。
