# キャプチャと共有

スクリーンショットと録画はMain > Tools > Captureにあり、Color、OCR Text、QR Code、TranscodeはMain > Toolsに直接配置されています。Control Center > Toolsからも同じ操作が可能です。

## スクリーンショットと抽出

- **Print:** フローティングエディタで全画面スクリーンショット。
- **SUPER + Print:** フローティングエディタで画面静止選択キャプチャ。
- **SUPER + Shift + Print:** エディタでアクティブウィンドウのスクリーンショット。
- **SUPER + Ctrl + Print:** 選択範囲からテキストをOCR抽出。
- **SUPER + Alt + Print:** 選択範囲からQRコードを読み取る。
- **SUPER + =:** 色を抽出してコピー。

スクリーンショットの撮影後、キャプチャした領域に短い稲妻のようなフラッシュが走ります。これは画像が撮影された後に開始されるため、スクリーンショット自体に写り込むことはありません。

保存または共有する前に、選択した内容を確認してください。OCR結果に誤りがある場合や、QRコードに個人認証情報や信頼できないURLが含まれている場合があります。スクリーンショットエディタを使用しても、背景にある機微なテキストが確実に除去されているとは限りません。

保存されたスクリーンショットの通知からは、画像を開く、スクリーンショットエディタで編集する（上書き保存）、装飾する（Beautify）、画面上にピン留めする、保存先フォルダを開くといったアクションが提供されます。

**Beautify**は、スクリーンショットを背景（テーマのグラデーション、いくつかのプリセット、アクセントカラー、または背景なし）の上に配置し、パディング、角の丸み、影を調整できます。**Copy picture**はフルサイズの画像をクリップボードにコピーし、**Save picture**は元のファイルの隣に`NAME-beautified.png`として保存します。

**Pin on screen**は、スクリーンショットを参照用としてすべてのウィンドウの手前およびすべてのワークスペース上にフロート表示します。ドラッグして移動し、画像上でスクロールしてサイズを変更できます。×ボタン、Escape、またはマウスの中央クリックで閉じます。

## 録画と配信

Screen Recordingを開くとOBSのコントロールが表示されます。これらは設定されたOBSシーンと保存されたWaylandキャプチャ権限を使用します。シーンには表示可能なモニターソースが含まれている必要があります。キャプチャを開始するとOBSが準備され、録画が始まる前にパネルが閉じます。コントロールはOBSのWebSocketを使用しますが、OBSの初期状態では無効になっています: EitrはOBSが閉じている間に初回起動時にパスワード付きでこれを有効化します。

その際にOBSが開いている場合は、一度閉じてからやり直してください。録画はホームフォルダ内の**Videos/Records**に保存されます。OBS自体のデフォルトはホームフォルダ直下ですが、Eitrはそのデフォルトのみを変更するため、OBS > Settings > Outputで独自に選択したフォルダはそのまま維持されます。OBSが録画または配信を行っている間、時計のすぐ左に赤いドットが表示されます。

このドットをクリックすると、経過時間とファイルサイズ、一時停止/再開、停止、チャプターマーカー（OBSのHybrid MP4形式が必要）、OBSのマイクとカメラ、シーンが表示されます。配信中は専用の停止ボタンが付いたLIVEタイマーが表示されます。録画が停止すると、通知からPlay recording、Open folder、Copy pathが提供されます。

開始する前に、オーディオ/マイクの選択および選択されたモニターを確認してください。Webカメラを使用するにはOBSのカメラソースが必要です。録画オーディオのスイッチはOBSの入力にのみ影響し、システムの音量には影響しません。

ハンドブックから録画や配信が開始されることは決してありません。画面共有やキャプチャは常に明示的な操作として行われます。Transcodeは既存の画像/動画変換ワークフローを提供します。ファイルを置換する前に出力パスを確認してください。

OBSが閉じている場合、Recordはフォーカスされているディスプレイをキャプチャします: Eitrはセレクターを表示することなくOBSの画面リクエストに自動で応答し、OBSのキャンバスをそのディスプレイのサイズに設定します（縮小された出力でも縦横比は保持されます）。自分で開いたOBSウィンドウは、すでにキャプチャしている内容をそのまま録画し続けます。録画停止後、Eitrは自身が起動したOBSを閉じるため、次回の録画でも再びフォーカスに従います。ビデオ通話など画面を共有する他のアプリでは、引き続きHyprlandの共有セレクターが表示されます。自分で編集した`~/.config/hypr/xdph.conf`は保持されるため、その場合は毎回セレクターが表示されることがあります。

新しいOBS設定の場合、Eitrは「Untitled」コレクションを1つのScene（画面キャプチャ、非表示のカメラ、デフォルトのデスクトップおよびマイク音声）とともに作成します。カメラは有効にするまでオフのままです。既存のコレクションが変更されることは決してありません。

## 共有

Main > Tools > ShareにはLocalSendおよび既存の転送ツールが用意されています。ファイルを送信するには、送信先/デバイスを選択する必要があります。受信者を確認し、秘密鍵、復旧コード、トークン、または未確認のホーム/設定フォルダ全体を誤って共有しないよう注意してください。
