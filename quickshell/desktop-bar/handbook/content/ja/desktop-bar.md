# デスクトップバーとワークスペース

<!-- eitr-figure: bar-anatomy -->

フルバーの構成。Eitrロゴをクリックするとコントロールセンターが開き、続いて概要、ワークスペースマーカー、AI使用状況、ハードウェア、アイドルロックが並びます。中央には日時が配置され、その前にメディア、後ろに天気が表示されます。**アイコンを表示**で右側のステータスアイコンの表示/非表示を切り替えられます。末尾には通知が配置されます。

プラグインの項目は、自動ロックの後、時計の前、時計の後、またはステータスグループに表示できます。設定 > プラグイン > 対象のプラグイン > バー上で位置を選びます。配置順に、自動ロックの後は4個、時計の両側は各2個、ステータスは8個までです。上限を超えた項目は選択した位置で非表示になります。Centered と Dynamic では展開時に表示され、Tabs と Islands では含まれ、Drop ではバーのプラグイン項目は非表示です。時計は画面の中央を保ちます。World clock は任意で追加できる公式プラグインで、バーの12/24時間設定に従います。

Weather は公式の組み込みプラグインで、初期状態では時計の後にインストールされます。Eitr Store > インストール済み > プラグインで削除すると、Drop のホームを含むすべての場所で天気が非表示になります。更新後も削除したままです。「見つける」からパッケージ内のコピーを使って再インストールでき、ダウンロードは不要です。都市検索の選択はセッション中だけ有効です。

設定 > ウィンドウでは、「ウィンドウレイアウト」と「モニター」に2ボタンの選択肢が使用されます。「ワークスペースの数」と「常に表示」にはドロップダウンリストが使用され、「常に表示」では2から現在のワークスペース数までを選択できます。各設定の下にある説明文には、選択されたウィンドウレイアウトやスクロールオプションなど、その効果が記載されています。

## アップデート

通知アイコンの前にあるアップデートアイコンは、ログイン直後と6時間ごとにチェックを行います。クリックするとシステムアップデートが実行され、右クリックで再チェックします。システムアップデートが正常に完了すると、次のチェックまで最新の状態としてマークされ、すぐに別のチェックを開始することはありません。オフライン時や失敗したチェックでは利用不可の状態が表示され、誤って「最新」と表示されることはありません。チェックには専用のパッケージデータベースが使用され、パッケージのアップグレードは行われません。

## バーのレイアウトの変更

- **バーの空き領域**を左ダブルクリックすると、テーマカラー → ぼかし → ウェブサイトの順に切り替わります（新規インストール時はテーマカラーから始まります）。ウェブサイトはEitrウェブサイトの配色を使用し、テーマに合わせてライトまたはダークになります。
- 空き領域を右ダブルクリックすると、フル → センター → タブ → アイランド → ダイナミック → ドロップ → フルの順に切り替わります。
- 空き領域を画面の上、下、左、右にドラッグしてバーを移動できます。左右のバーも上下のバーと同じ細さです。時計はカレンダーアイコンとともに時と分が上下に表示され、天気はアイコンのみが表示されます。ホバーすると日付と気温が表示されます。
- 設定 > デスクトップバーにある**時計**では、どのバーの端でも12時間表記（AM/PM付き、デフォルト）または24時間表記を選択できます。
- 同様の設定は**設定 > デスクトップバー**の「レイアウト」、「外観」、「動作」タブにも用意されています。
- **ディスプレイ**（表示先）では、バーをデフォルトのメインディスプレイのみに配置するか、すべてのディスプレイに配置するかを設定できます。すべてのディスプレイに配置した場合、各バーは自身の画面に表示されているワークスペースを示し、SUPER + Iなどのショートカットは使用中のディスプレイで開き、通知はメインディスプレイにのみポップアップ表示されます。メインディスプレイはディスプレイパネルで選択します。

右ダブルクリックで循環する6つのレイアウトの順序。静止状態では、センターは時計のみ、ダイナミックは3つの小さなアイランド、ドロップは単一の時刻ピルのみを表示します。センターとダイナミックはホバー時に展開されます。

設定 > デスクトップバーでレイアウトを選択します。6つのレイアウトはすべて画面のどの端でも機能します。

| レイアウト | 動作と特徴 |
| :--- | :--- |
| フル | フルはバー全体を画面端に維持します。パネルはバーに接続されます。 |
| センター | センターはホバーするまで時計のみを表示します。ピン留め、または設定 > デスクトップバーの「展開状態を維持」（Walker内にもあり）を使用して展開したままにできます。パネルはバーの横にフローティング表示されます。 |
| タブ | タブは細いストリップで結ばれた3つのタブを使用します。ステータスアイコンと天気は常に表示されます。 |
| アイランド | アイランドは各グループに独立したピルを割り当て、すべてのステータスアイコンを常に表示します。パネルを開くとそのピルが拡大し、隣接するグループが横に移動します。 |
| ダイナミック | ダイナミックはロゴ、時計、ネットワーク/バッテリーの3つのアイランドから始まり、メディア再生中はロゴと時計の間にメディアアイランドが追加されます。ホバーすると展開され、パネルを開くとそのアイランドからパネルへと拡大します。 |
| ドロップ | ドロップは画面端の中央にある1つのピルに時刻のみを表示します。クリックするとダッシュボードへと拡大し、右クリックするとクイックコントロールに直接移動します。自動非表示を使用すると、端からしずくが落ちてピルへと膨らむまで、画面には何も表示されません。 |

**アイランドのスタイル**（設定 > デスクトップバー > レイアウト、または Walker > 設定 > デスクトップ > デスクトップバー > アイランドのスタイル）では、アイランド、ダイナミック、ドロップが画面の端とどう接するかを選びます。フローティングでは外側の余白の半分だけ端から浮かせ、アタッチでは端に付けて端側を角張らせ、側面をまっすぐにします。パネルも端から開きます。**側面のスタイル**では、タブとセンターが端とどう接するかを選びます。45°の斜面か、まっすぐな辺です（まっすぐな辺のタブでは、タブの間の細い帯もなくなります）。

## ドロップのダッシュボード

ドロップの時刻ピルをクリックすると、ピル自体がダッシュボードへと拡大します。ページを横にドラッグするか（右で次へ、左で前へ、端まで行くと循環）、矢印キーや水平スクロールを使用します。Escまたは外側をクリックすると閉じます。ダッシュボード内の項目から別のパネルが開くことはなく、戻る矢印とともにその場で詳細が開きます。

| ページ | 表示内容 |
| :--- | :--- |
| カレンダーと天気 | 月の横に天気が表示されます。天気をクリックすると詳細な予報と都市検索が開き、日をクリックするとその日の予定の確認やその日の時間指定リマインダーの追加ができます。 |
| メディア | 音楽に合わせて動くバーに囲まれたアートワーク、曲名、歌詞、操作コントロール、プログレスバーが表示されます。メディア再生中に表示されます。 |
| OBS | 一時停止、停止、配信開始を含む録画と配信のステータス、チャプターマーク、録画先フォルダ、OBS本体へのリンクが表示されます。OBSの起動中に表示されます。 |
| クイックコントロール | Wi-Fi、Bluetooth、サウンド、マイクをクリックすると、その場でネットワークやデバイスが開きます。機内モード、消音、夜間モード、アイドルロック、録画、設定、音量、マイク、および（ノートPCでは）輝度を操作できます。 |
| タイマーとフォーカス | カウントダウン、ストップウォッチ、または5分間の休憩を挟む25分間のフォーカスセッション。ダッシュボードを閉じてもバックグラウンドで動作し続け、終了時に通知します。 |
| パフォーマンス、AI使用状況、通知 | CPU、GPU、RAM、ストレージ、各アシスタントの使用制限（1つクリックするとすべて表示）、通知一覧が表示されます。 |

どのレイアウトでも、時計の横（録画ドットの位置）に現在の状況が表示されます。イベントが10分以内に始まる場合はカレンダーマーク（クリックするとその日の予定を表示）、タイマーまたはフォーカスセッションが動作中の場合はリング（クリックするとコントロールセンター > ツール > タイマーとフォーカスを表示）が表示されます。新しい通知が届くとバーのベルが2回鳴ります。ベルが非表示の場所（収納時のセンター、静止時のダイナミック）では、代わりに時計の横からベルがスライドして現れます。ノートPCのバッテリー残量が15%および5%になると、時刻の代わりに赤いパーセント表示が一瞬現れます。ワークスペースが非表示の場所では、切り替えたワークスペース番号も同様に一瞬表示されます。

ドロップのピルでは時刻の周囲に状況が表示され、必要なときだけスペースを確保します。時刻の前: 録画中は赤いドット、イベントが10分以内に始まる場合はカレンダーマーク、タイマー動作中はリング、バーがアップデートを確認中は回転する矢印、通知表示中はアップデートマーク（クリックするとシステムアップデートを実行）、音楽再生中は音符（クリックするとメディアを開く）が表示されます。時刻の後: 新しい通知が届くと2回鳴るベル（クリックすると一覧を表示）。ワークスペースを切り替えると、時刻の代わりにその番号が一瞬表示されます。ノートPCのバッテリーも15%および5%で同様に赤く表示されます。音符を右にドラッグするとピルが1行の歌詞表示に切り替わり、どちらかの方向にドラッグするか一時停止または停止すると元に戻ります。

**オンライン歌詞**（設定 > デスクトップバー > 動作、またはWalker > 設定 > デスクトップ > デスクトップバー > オンライン歌詞）はデフォルトでオフになっています。オンにすると、ドロップは再生中の楽曲をLRCLIB（lrclib.net）で検索し、曲名、アーティスト、アルバム、再生時間を送信します。プレーヤー自身が送信する歌詞がある場合は、常にそれが最優先で使用されます。

## ワークスペース

設定 > ウィンドウ > ワークスペース（またはWalker > 設定 > デスクトップ > ウィンドウ > ワークスペース）で、**モニター**、**ワークスペースの数**（5〜10、デフォルトは10）、**常に表示**（2から全体の数まで、デフォルトは5）を選択できます。デフォルトの**番号を共有**では、各モニターに独自の1…Nが割り当てられます。SUPER+kですべてのモニターを連動して切り替え、SUPER+Shift+kで現在のモニター上のウィンドウを移動し、すべてのモニターがその番号に連動して切り替わります。**モニター間で分割**では、N個のワークスペースを均等に分割し、メインディスプレイを優先して端数を最初に割り当てます。その他のディスプレイは左から右へ、続いて名前順に割り当てられます。SUPER+kは所有するディスプレイにフォーカスを移動します。Nを超えるキーを押しても何も起こりません。マーカーの表示下限は各モニターの範囲に応じた相対的なものとなり、現在のワークスペースまたは使用中の最も大きな番号のワークスペースまで表示され、不要になると非表示になります。ディスプレイの接続や取り外し、メインディスプレイの変更時には、ウィンドウを失うことなく割り当てが再計算され、ウィンドウは現在のディスプレイで最も近い有効な番号に移動します。1台のモニターでは、どちらのモードでも同じ動作になります。
マーカーを右クリックすると、ドット、グリフ、数字、ルーンをライブプレビュー付きで選択できます。
どのバーの端でも、4つの選択肢すべてがスクロールなしでポップアップ内に収まります。
ルーンがデフォルトです。アクティブなマーカーは、塗りつぶされた背景なしでアクセントカラーのグリフを使用します。
ルーンは、ワークスペース1〜10を最初の10個のエルダー・フサルク・ルーン文字（ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ ᚷ ᚹ ᚺ ᚾ）として表示します。

**SUPER + 1–9/0**でワークスペースを切り替えます。**SUPER + Shift + 1–9/0**でウィンドウを移動します。
**SUPER + Tab**でワークスペース概要を開きます。プレビューをクリックするか、矢印キーとEnterを使用します。
1–9/0で直接切り替えることもできます。ウィンドウが存在する番号付きワークスペースのみが表示され、そのプレビューはメモリに保持されます。Escapeまたは外側をクリックすると概要が閉じます。

**SUPER + S**で特殊ワークスペースを切り替えます。これは概要とは別です。
**SUPER + Shift + Space**でバーの自動非表示をオンまたはオフに切り替えます。コントロールセンターからバーが非表示にされていた場合は、まずバーを再表示します。どちらの場合でも通知は正常に機能し続けます。

デスクトップの空き領域での壁紙やテーマのマウスジェスチャーは、**Learn > Mouse Gestures**に記載されています。不明な場合は、キーボードのカルーセルショートカットを使用してください。

オーディオ/マイクコントロールをクリックすると、出力とマイクが分かれた単一のパネルが開きます。配信コントロールはOBSの直前に配置されています。ヘッダーのスイッチで共有を開始し、詳細が続き、「…」メニューにはセットアップや診断アクションがあります。アイコンボタンはホバー時に背景が表示されます。パネルは開いたときに自動で更新され、読み込み中のみ更新アイコンが回転し、ツールチップはポインターの近くに表示されます。スイッチやはめ込みアクションボタンにはコンパクトな共通サイズが使用されます。

**Music Visualizer**はテーマカラーでcavaを開きます。メディアのイコライザーを右クリックすると同じビジュアライザーが開き、左クリックするとメディアの詳細が開きます。**q**または**Esc**を押して閉じます。既存のデスクトップ環境でcavaパッケージがない場合は、自動的にインストールされます。

設定 > デスクトップバーにある**自動非表示**は、ポインターが離れてから少し遅れてバーをスライドさせて格納します。画面の端に触れると再表示されます。フル、センター、タブ、アイランド、ダイナミック、ドロップのすべてのレイアウトで4つの端すべてに対応しています。ドロップでは、バーの色をしたしずくが端から落ちて時刻ピルへと膨らみます。新しい通知が届くと、そのポップアップが閉じるまでバーが表示されたままになります。パネルやポップアップを開いている間、およびバーをドラッグしている間は表示が維持され、操作後に再び非表示になります。自動非表示がオンの間、バーはウィンドウ領域を予約しません。ウィンドウを移動させるのではなく、ウィンドウの上にスライドして重ねて表示されます。この設定はセンターレイアウトのピン留めとは独立して保存され、新規インストール時はデフォルトでオフになっています。

設定 > デスクトップバーにある**視覚効果を減らす**をオンにすると、パネルの展開と収納、概要の開始アニメーション、通知のトランジション、装飾的なバーのアニメーションが瞬時に行われます。デフォルトではオフになっており、`bar-settings.json`に保存されます。データの更新タイマー、通知を消去するタイマー、自動非表示の遅延タイマーは通常の動作を維持します。

メディアのスタイルは`bar-settings.json`に保存されます。設定 > デスクトップバーでバー（デフォルト、10本のバー）またはライン（滑らかな単純な音波）を選択します。インジケーターは再生コントロールの前に配置され、どのレイアウトでも固定サイズを保ち、左右の端では回転します。ホバーすると曲名が表示され、左クリックでメディアの詳細が開き、右クリックでMusic Visualizerが開きます。左にドラッグするとその場所に1行の歌詞が表示され、その行をどちらかの方向にドラッグすると元に戻ります。再生を一時停止するとラインは平らに静止します。「視覚効果を減らす」がオンの場合、イージングなしでリアルタイムの音声レベルを維持し、装飾的なフォールバック動作を停止します。

## エッジドック

バーとは反対側の画面端に触れると、アプリケーションドックが表示されます。その端からまっすぐな側面でウィンドウの上に展開され、ウィンドウを移動したりサイズ変更したりすることはありません。ポインターが離れてから350ミリ秒後に非表示になり、共通の320ミリ秒の動作（「視覚効果を減らす」がオンの場合は瞬時）で収納されます。メイン画面に表示されるほか、「ディスプレイ」が「すべて」に設定されている場合はすべての画面に表示されます。全画面表示のウィンドウの上に現れることはありません。

ドックにはピン留めされたアプリが最初に表示され、続いてHyprlandのウィンドウ順に他の起動中アプリケーションが表示されます。各36 pxのアイコンスロットには6 pxの間隔があり、アプリケーションのデスクトップアイコンが使用され、グリフへのフォールバックもあります。Eitr独自のタスクターミナルとメニューターミナルは1つのEitrロゴアイコンを共有します。アイコンの下のドットはそのウィンドウの数を最大3つまで示し、その画面の現在のワークスペースにウィンドウが存在しない場合は暗くなります。

ホバーすると名前とウィンドウ数が表示されます。ポインターの近くにあるアイコンが拡大し（最も近いものが最大）、ドックが伸びてアイコンを内部に収めます（「視覚効果を減らす」がオンの場合を除く）。クリックすると最近使用したウィンドウにフォーカスし（ワークスペースの切り替えを含む）、再度クリックすると次のウィンドウに移動します。中央クリックで最新のウィンドウを閉じます。

長いリストはドックに沿ってスクロールします。ドックの表面はぼかし/テーマカラーおよび角の丸みの設定に従います。

**設定 > デスクトップバー**の**ドック**でオン/オフを切り替えます。`bar-settings.json`の`dock`設定はデフォルトで`"yes"`になっています。ドック用のショートカットはありません。

ピン留めされたアプリは、閉じているときはドットなしで完全な不透明度で表示されます。クリックすると専用のアプリケーションスコープで起動します。アイコンを右クリックすると、「ドックに保持」/「ドックから削除」、「新しいウィンドウ」（デスクトップエントリが利用可能な場合）、「閉じる」または「すべてのウィンドウを閉じる」が表示されます。Escapeまたは外側をクリックするとメニューが閉じます。デスクトップエントリのないアプリはピン留めできません。

ドックに沿ってアイコンをドラッグするとピンの並び順を変更できます。実行中のアプリをピン留めセクションにドラッグするとそこに保持され、ピンをそのセクションの外にドラッグするとピン留めが解除されます。他のアイコンは短いアニメーション（「視覚効果を減らす」がオンの場合は瞬時）でスペースを空けます。ピン留めされていないアプリはHyprlandのウィンドウ順を維持します。細い区切り線は、両方のセクションにアプリがある場合にのみピンと他の実行中アプリを分離します。メニューやドラッグ操作中はドックが表示されたままになります。

ピンはデスクトップエントリのIDであり、`$XDG_CONFIG_HOME`（通常は`~/.config`）配下のマシンローカルな`quickshell/desktop-bar/dock-pins.json`に順番に保存され、アトミックに書き込まれます。新規インストール時にはピンはありません。ウィンドウの一致判定にはデスクトップエントリID、StartupWMClass、およびアプリケーションクラスが使用されます。

ぼかしの強さはターミナルと共有されます。Walkerのデスクトップバーまたは設定（SUPER + ,）で「控えめ」、「標準」（デフォルト）、「強め」を選択します。全体的なぼかしの制限と個人的な上書きについては[ターミナルとエディタ](handbook:terminal)をご覧ください。

設定 > デスクトップバーにはワークスペースマーカー（ドット、グリフ、数字、ルーン）が含まれます。「ウィンドウ」ページにはウィンドウ効果と間隔の設定があります。
