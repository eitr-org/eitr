# 情報、メディア、通知

通知カードには、ポップアップと通知履歴の両方で、タイトルの下にローカルの受信日時が表示されます。日時はこのセッションの間のみ保持されます。

## システム情報の確認

設定 > バージョン情報 を開くと、Eitr のバージョン、コードネーム、アップデートチャンネル、カーネル、ライセンス、およびこの PC のプロセッサ、グラフィックス、マザーボード、搭載メモリ、接続されている各ドライブとその容量を確認できます。システム概要には、プロファイル、現在のハードウェア使用状況、ネットワーク速度（ダウンロードとアップロード）が表示されます。詳細なハードウェア、AI使用状況、天気を表示するには、バーのアイコンをクリックします。Walker で名前を検索して見つけることもできます。

設定 > バージョン情報 の「ロゴ」で「エンブレム」または「ルーン」を選択すると、ターミナルのバージョン情報ページを変更できます。この選択はこのマシンに保存され、デフォルトは「エンブレム」です。どちらも現在のテーマのアクセントカラーに従います。

**ハードウェア** には、CPU、GPU、RAM、および `/` を担うドライブのストレージが表示されます。他のディスクはその合計には含まれません。取得できないセンサーや GPU のテレメトリは利用不可としてマークされます。

**AI使用状況** は、インストールまたは設定済みのクライアントを検出します。キャッシュされた使用状況が最初に表示され、更新を行ってもサインインや対話が開始されることはありません。各アカウントの上限が表示され、パーセンテージは上限に対してすでに使用された割合を示します。Claude、Codex、Grok、Antigravity ではプランの上限を読み取ることができます（Antigravity はモデルグループごと: Gemini、Claude & GPT、Argon）。Copilot CLI、OpenCode、Pi、または API キーを使用する Gemini CLI などの従量課金制アシスタントにはエントリがありません。

検出された各プロバイダーには、プラン、上限、エラーを含む独自のセクションがあります。見出しをクリックすると、そのセクションのみを折りたたんだり展開したりできます。セクションはログイン時に閉じた状態で開始され、セッション中は開閉状態が維持されます。長いリストは画面内でスクロールします。

**天気** はデフォルトの位置情報を使用し、一時的な都市検索をサポートしています。パネルを閉じると一時的な指定は終了します。Escape を押すとパネルを閉じる前に都市検索がクリアされます。温度の単位は位置情報に従い、代替単位も併記されます。

## カレンダーとメディア

時計または日付をクリックするとカレンダーが開きます。カレンダーは6週分の行を保持し、グリッドの下に年の進行状況を表示します。前へ/次へボタン、「今日」、矢印キー、または T で移動できます。バーが非表示の場合は、Walker からカレンダーを検索してください。日付をクリックするとグリッドの下にその日のリマインダーが表示されます。日付の横の「+」をクリックするとその場で予定が開き、その日の指定時刻にリマインダーを追加するフィールドが表示され、戻る矢印で月表示に戻ります。

アニメーション表示されるイコライザーをクリックすると「メディア」パネルが開きます。音楽に合わせて動くバーで囲まれたジャケット画像、曲名、歌詞、前へ/再生/次へ、およびサポートされている場合はシーク操作が表示されます。対応するプレーヤーがない場合は非表示になり、認識されたオンライン会議は除外されます。バーのイコライザーは、再生中かつバーが表示されている間のみ、プライベートな cava プロセスを通じてライブのシステムオーディオに連動します。イコライザーを左にドラッグすると歌われている歌詞の行と入れ替わり、その行をどちらかにドラッグすると元に戻ります。一時停止や曲の変更を行っても状態は維持されます。オンライン歌詞はデスクトップバーの設定です（デスクトップバーの章を参照してください）。

## 通知

**SUPER + N** またはベルのアイコンをクリックすると通知センターが開きます。通知はアプリケーションごとにグループ化されます。最新のカードがスタックの先頭に表示され、展開して古いカードを確認できます。個別のカードを閉じたり、意図的にグループまたはすべてを消去したりできます。ポップアップもアプリごとにスタックされ、重なったレイヤーの上に最新のメッセージが表示されます。ポインターを重ねると有効期限のカウントダウンが一時停止します。

**SUPER + Alt + N** は最新の通知のメインアクション（クリックしたときの動作）を実行し、**SUPER + Alt + Shift + N** は通知を閉じます。重複した通知（同じアプリ、タイトル、本文）は以前の通知を置き換え、別のカードを重ねる代わりに「×3」のようなカウントを表示します。

通知をクリックすると、そのメインアクションが実行されます。アクションのない通知をクリックすると、送信元のアプリが開きます（アプリのウィンドウ、または herdr の場合は herdr を実行しているターミナルが、通知に示されたワークスペースとタブに切り替わって開きます）。各カードには、アプリ固有のアイコンがある場合はそれが表示され、ない場合はベルのアイコンが表示されます。

ポップアップはすべてのディスプレイに表示されます。メインディスプレイにのみ表示するには、設定 > 通知 で「すべてのディスプレイにポップアップを表示」をオフにします。同じページには「応答不可」と「クラッシュ通知」の設定もあります。
