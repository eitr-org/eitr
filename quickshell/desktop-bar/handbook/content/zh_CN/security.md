# 安全与锁定

**SUPER + M** 可立即锁定屏幕。点击桌面栏左侧（“AI 用量”之后）的“空闲锁定”图标可开启或关闭空闲自动锁定；其悬停提示会标明当前状态。开启时，空闲 15 分钟后屏幕锁定，30 分钟后关闭屏幕，60 分钟后电脑进入睡眠模式。控制中心同样提供该空闲锁定开关以及“锁定”按钮。

在锁定前 20 秒，受支持的显示器会将亮度调暗至先前亮度的约 30%（绝不会降为零）。任何活动操作（即便在锁屏之后）都会立即将亮度完全恢复至先前的级别；关闭空闲锁定同样会恢复亮度。不支持 DDC 亮度调节的外接显示器会被自动跳过。

## 密码与备选身份验证

**设置 > 用户 > 更改密码**可更改您的账户密码，并保持登录密钥环与其同步解锁。
指纹和 FIDO2 安全密钥拥有专属的录入/启用工作流。FIDO2 安全密钥是实体硬件安全设备，而非笔记本电脑的指纹读取器。
请先录入凭据，然后再启用身份验证。辅助程序会自动备份 PAM 设置；操作前请务必确保密码可用且有途径访问 TTY 控制台。

“返回密码身份验证”可恢复为仅使用密码的机制。这些更改会影响受支持的锁屏/登录/sudo PAM 服务；需要相应的硬件支持及已安装的辅助程序。指纹身份验证可能会使密码输入提示出现轻微延迟。仅阅读本页面不会修改任何 PAM 配置。

## 管理员密码提示

当应用程序或 Eitr 本身需要管理员权限时（例如安装软件、更改系统设置），一个采用桌面栏主题配色的密码提示界面会覆盖您当前使用的屏幕。它会清晰显示发起请求的程序、由哪个账户进行身份验证（在有多个可用账户时提供选择），以及包含对应 polkit 操作的“请求详情”。按 Enter 进行身份验证，按 Escape 或点击“取消”可拒绝请求；在提示界面旁边点击无效。密码错误时会显示提示并允许重试。多个权限请求会依次排队等待处理，一次仅弹出一个提示。密码会直接提交给系统，绝不会被保存或记录。

如果桌面栏在登录后不久无法提供该提示界面，KDE 的密码对话框会在当前会话中接替该工作，以确保管理员权限请求始终能够正常运作。

## 防火墙

新安装的系统默认启用防火墙。它会拒绝所有传入连接，但以下情况除外：对本机主动发起的请求的响应、本地名称发现，以及 Eitr 安装的共享应用：KDE Connect（端口 1714-1764）和 LocalSend（端口 53317）。本机上的虚拟机和容器依然可以访问宿主机，传出流量绝不会受到过滤。当启用 SSH 时，SSH 端口同样保持可连通。

**设置 > 安全 > 保护 > 防火墙**显示其当前开关状态，并在您确认后进行切换。在防火墙功能推出之前配置的电脑默认处于关闭状态。如需允许其他应用接受传入连接，请在 `/etc/eitr/firewall.d/` 中添加文件，例如包含以下内容的 `game.nft`：

```
add rule inet eitr_firewall input udp dport 27015 accept
```

然后将防火墙关闭并重新开启即可。

## 磁盘加密与 TPM

磁盘加密是在系统安装时决定的选项。“TPM 磁盘解锁”可为受支持的现有 LUKS2 根分区添加 TPM2 槽位；安装程序不会自动完成该录入。请务必在线下妥善保管密码短语/恢复密钥。切勿将其保存在屏幕截图或代码仓库文件中。固件或安全启动 (Secure Boot) 的变动可能会导致下次启动时必须输入密码短语。

在更改身份验证或 TPM 配置之前，请务必阅读[恢复与快照](handbook:recovery)。[安全启动](handbook:secure-boot)是一项高级的手动操作过程：EITR 不会自动为您录入固件密钥或签署引导文件。在某些硬件上，任何操作失误都可能导致系统无法引导甚至无法进入固件设置界面。

## 用户账户

**设置 > 用户 > 创建用户…** 可创建独立的登录账户。输入用户名、可选全名、账户类型和密码，随后审查并在确认后按 Enter 创建。在确认应用前按 Esc 可取消。标准账户无法使用 sudo；管理员账户将加入 wheel 组并获得受密码保护的 sudo 规则。

新用户的主目录不包含您账户中的任何文件。通过 UWSM 首次登录 Hyprland 时，Eitr 会运行安装程序的每用户桌面配置，并在新用户的身份下适配软件包布局。Shell 配置可能需要联网。失败的配置过程会保留待处理标记以便下次登录时继续执行；成功的配置仅运行一次。账户创建失败时会留下处于锁定和过期状态的不完整账户，以供手动检查。

管理员在“设置 > 用户”中可看到**用户**和**管理**两个标签页；标准账户只能看到用户列表。管理员属于 wheel 组并拥有 Eitr sudo 规则；标准账户两者皆无。“管理”页面可以创建账户、更改账户类型、设置其他账户的密码以及删除账户。每项操作都会先弹出一个确认浮层，随后打开一个任务终端：按 Enter 继续，按 Esc 取消。重置密码需要在终端中输入两次新密码；另一个账户的登录密钥环无法自动更新，将保留其旧密码。如需修改您自己的密码，请在“用户”页面上点击“更改密码”。删除账户时默认保留其主目录；勾选“删除用户主目录”才会彻底删除其文件。您无法删除自己、存在活动登录会话的账户或唯一的管理员；唯一的管理员同样无法被降级。仅能管理人类用户账户（UID 1000–65533）。从终端返回后列表会自动刷新。

主要用户组为 wheel 的账户无法在此处直接降级；必须先通过手动系统管理更改其主要用户组。

## 个人资料头像

“设置 > 用户”列出了此电脑上的所有账户。点击其中的头像可进行更换，或使用下方的垃圾桶图标将其移除。有关选取图片和调整裁剪的说明，请参阅[设置](handbook:system)。控制中心仅用于展示您的头像。
