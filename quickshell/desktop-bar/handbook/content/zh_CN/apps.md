# 应用程序与安装

在安装官方软件包之前，终端会显示它正在检查待处理的系统更新。在请求管理员密码之前，该检查可能需要一些时间。Flatpak 安装也会提示其准备阶段。如果有待处理的更新，它会说明原因：Arch 仅在最新的系统上安装应用程序，现在安装也会在没有恢复快照的情况下升级部分系统。按 Enter 运行带有快照的“系统更新”然后执行安装；按 Esc 取消而不更改任何内容。

**SUPER + 空格键** 和“主菜单 > 应用”打开同一个应用程序列表。按 Enter 启动应用程序。按 Delete 在“应用”中可用，并提示确认卸载。通过 **SUPER + F** 进行的全局搜索可启动应用，但不提供卸载操作。没有单独的基于固定项的应用菜单。

在主菜单中键入可搜索所有子菜单中的已安装应用和操作。在子菜单（如“系统”或“安装”）内部键入，可搜索该子菜单及其下方的所有内容。键盘布局和云账户下层内容（服务、资源、日志）仅在其自身菜单内部搜索；云账户列表保留在搜索中。

动态菜单还会搜索已加载的子操作，例如已安装插件或 Git 账户内部的操作。键入操作会复用菜单已加载的内容；打开资源选择器或“视觉效果”可搜索需要额外提供商读取的选项。子菜单行以 **>** 结尾；按 **Shift + Backspace** 可返回父菜单。

## 选择默认应用程序

打开“设置 > 默认应用”以选择用于打开网页链接、文件、文本、图像、视频、音乐、邮件和 PDF 的已安装处理程序。其“终端”选项与“外观 > 终端”共享。音乐文件在 Decibels 中打开，除非您选择其他播放器；GNOME Music（如果已安装）仅播放其自身音乐库中的歌曲，无法直接打开文件。

## 安装

在命名的“安装”列表中，对已安装的条目按 Delete 键可在确认后将其卸载。网页应用保留其移除操作。软件包（Pacman 和 Yay）使用 Ctrl+D 在确认后移除高亮显示的已安装软件包。Ctrl+F 切换仅显示已安装软件包或显示全部软件包。Eitr 软件包保持安装状态。绝不会递归移除必需的系统依赖项；pacman 会拒绝破坏其他软件包的移除操作。

托管语言包在终端中显示其完整的移除警告，然后使用 [y/N] 请求确认；按 Enter 取消。移除 Node 包含所有由 NVM 管理的版本及其全局 npm 工具。移除 Python 会影响由 uv 管理的版本和 uv，而不影响系统 Python。Java 移除当前的 SDKMAN Java 和 Maven 版本；Rust 仅移除其稳定工具链。Rails 和 Laravel 移除其框架工具，同时保留 Ruby、PHP 和 Composer。项目、设置和凭据均予保留，但依赖的工具和环境可能会停止工作。原生助手移除保留缓存的版本和设置。

系统中已有的应用程序在其名称下方显示**已安装**；选择其中之一会提示该状态而不是重新安装。这还可以识别由其自身管理器安装的工具，例如来自 SDKMAN 的 Java 或来自 NVM 的 Node.js。需要运行时的软件包（例如 DBeaver 的 Java）仅在尚无软件包提供时才引入小型运行时。

- **AI CLI：** 可选的 AI 命令行客户端。
- **浏览器：** 受支持的浏览器选项。
- **数据库：** 可选工具，例如 DBeaver、数据库客户端和 Valkey（Arch 随附用于替代 Redis 的兼容服务器）。
- **开发语言：** 可选语言工具链；Java/Flutter 不是强制的桌面依赖项。
- **JavaScript 工具：** 可选的 JavaScript 运行时和工具链。
- **软件包 > Pacman** 与 **软件包 > Yay (AUR)：** 搜索官方 Arch 软件包或社区 AUR 软件包，每个均标明其来源以及是否已安装。搜索栏位于顶部，软件包位于其下方，所选软件包的详情位于底部；按 **Ctrl+B** 可切换查看其构建文件 (PKGBUILD) 并返回，按 **Ctrl+O** 在浏览器中打开其主页，按 **Tab** 选择多个，按 **Enter** 进行安装。AUR 软件包是在本机根据其构建文件构建的，因此请先阅读构建文件；它们不是官方 Arch 软件包。

安装/更新/设置终端显示带主题样式的 EITR 横幅。成功的任务通常会自动关闭；失败的任务保持可见。清理等报告保持打开状态以便阅读。常规终端和“关于”窗口不显示任务横幅。

按 **Esc** 关闭处于等待状态的任务、账户、报告和“关于”终端。Enter 仍用于作答和确认，包括确认恢复密钥和关闭安装程序电源。

使用 `eitr package install 名称` 安装单个官方软件包，使用 `eitr package install --aur 名称` 安装 AUR 软件包，或使用 `eitr package remove 名称` 移除软件包。这需要终端环境。主题审核界面显示软件包和来源：按 Enter 确认，按 Esc 取消。对于 AUR，Ctrl+B 阅读构建文件（按 q 返回），Ctrl+O 打开构建仓库。社区 AUR 软件包未经 Eitr 或 Arch Linux 审核。已安装的软件包会直接成功退出。失败的任务保持打开直到按 Esc。插件可以使用 `kitty --class eitr-menu-terminal -e eitr package install --aur lowfi`。

## 工具

“应用”中的**计算器**（或键盘上的计算器按键）在当前主题颜色下打开 Eitr 的计算器。键入或单击：`+ − × ÷`、用于乘方的 `^`、用于百分比的 `%`（如 `200×15%`）、`√` 和括号；括号前的数字表示乘法（如 `2(3+4)`）。按 Enter 显示结果，按 Backspace 删除字符，按 Escape 清除（按两次关闭），按 Ctrl+C 或**复制**复制结果。它是自行计算表达式，而不是将其作为代码执行。

**离线听写**是绝不离开本机的语音转文字功能。按住 **SUPER + D**，说话并松开：文字会以您所说的语言键入到光标所在位置。您也可以轻按 **SUPER + D**，说话，然后再次轻按。在聆听时，时钟左侧的红点会变成随声音跳动的小波形，因此您可以看出它听到了声音；松开后它会跳动，直到文字键入完成。

首次使用时会下载一次语音模型（148 MB，根据发布的校验和进行校验）到 `~/.local/share/eitr/whisper/`；此后它均离线工作。松开后转录需要稍等片刻，在较旧的处理器上耗时更长。松开 D 键时录音停止，即使先松开了 SUPER 也是如此，或者在 120 秒后停止；随后文字照常转录。

**主菜单 > 工具 > 提醒事项 > 新建提醒**会提示输入时间（如 `10m` 或 `1h30m` 的延迟，或如 `18:30` 的时刻）和事项内容，随后在该时刻显示带有稍后提醒和关闭按钮的通知。**即将到来的提醒**列出等待中的提醒；选择一项可将其取消。提醒事项在重启后依然保留，计算机关机期间到期的任何提醒都会在下次登录时显示。从终端运行：`eitr remind 25m 取出茶包`，单独运行 `eitr remind` 可列出提醒。

## 游戏

“主菜单 > 游戏”列出 **GeForce NOW**、**RetroArch** 和 **Steam**。选择一项会在已安装时打开它，否则进行安装。RetroArch 来自 Arch 官方软件包，内置经典游戏机核心：NES、SNES、Game Boy 和 Game Boy Advance、Mega Drive/Genesis、PlayStation、Nintendo 64、Nintendo DS、PSP 和 Dreamcast。添加您自己的游戏，在游戏机需要时添加其 BIOS 文件；Eitr 两者均不随附。GeForce NOW 通过 Flatpak 安装。

**快捷操作 > 游戏模式**在您玩游戏时让桌面不造成干扰：关闭窗口动画、模糊和阴影，通知弹出窗口进入等待（免打扰），并在计算机支持时将电源配置文件切换为高性能模式。关闭它可精确恢复所更改的内容。Steam 与 **GameMode** 和 **MangoHud** 一同安装：在 Steam 的游戏启动选项中添加 `gamemoderun mangohud %command%` 即可在游玩时提升 CPU 性能并显示 FPS 浮层。

LocalSend 打包的应用包含其运行时需求：仅运行它不需要 Flutter SDK。开发者工具依然是可选的。

升级请使用[更新与清理](handbook:maintenance)；安装单个软件包不同于受快照保护的“系统更新”工作流。

“主菜单 > 工具 > 娱乐”包含“音乐可视化工具”和“符文雨”。

**音乐可视化工具**打开带有主题颜色的 cava。右键单击媒体均衡器可打开相同的可视化工具；左键单击仍会打开媒体详情。按 **q** 或 **Esc** 可将其关闭。在现有桌面上，如果缺少 cava 软件包，会优先安装。

**符文雨**在屏幕上充满以主题颜色飘落的古弗萨克符文，偶尔会拼出 ᛖᛁᛏᚱ。按任意键可将其关闭。在终端中运行 `eitr matrix` 可在原地运行它；`--speed slow|normal|fast` 和 `--seconds N` 可更改其速度和持续时长。

当连接的显示器报告 HDR 支持时，Eitr 默认将 Steam Proton 游戏设置为 Wayland 和 HDR，附带 `PROTON_ENABLE_WAYLAND=1`、`PROTON_ENABLE_HDR=1` 和 `DXVK_HDR=1`。没有 HDR 显示器的计算机会保留其现有默认设置。当列出或更改显示器时，以及在登录或重新加载加载该配置之前，硬件检测都会刷新生成的显示配置。

启动新的桌面会话并重启 Steam 以继承更改后的默认设置；正在运行的 Steam 进程会保留其环境。在游戏内部启用 HDR；全屏游戏即使在桌面 HDR 关闭的情况下也能自动切换显示器。少数游戏在 Wayland 模式下会丢失 Steam 浮层。要为单个游戏选择停用，请将其 Steam 启动选项设置为 `PROTON_ENABLE_WAYLAND=0 %command%`。

要校准游戏，请根据显示器规格将其最大或峰值亮度设置为显示器的 HDR 峰值（DisplayHDR 400 显示器峰值约为 400 尼特），然后根据喜好调整纸张白度或整体亮度。如果高光细节丢失，请降低峰值；如果图像看起来暗淡，请提高纸张白度。

浏览器仅在其显示器开启桌面 HDR 时才使用 HDR；它们绝不会自动开启。全屏 HDR 游戏在桌面 HDR 关闭时仍会自动切换。浏览器 HDR 播放还取决于浏览器支持和设置。

## 语音提醒

按住 **SUPER + Shift + D**，说话并松开，或打开“主菜单 > 工具 > 提醒事项 > 告诉助手…”键入内容。Eitr 使用与听写相同的离线模型在本地转录，然后让您的“开发 > AI > 默认助手”解析请求。仅将转录文本和提醒上下文发送到该助手的提供商；音频保留在本地并在转录后删除。

助手通过 Eitr 的只读路径无头运行；Eitr 验证其 JSON 并自行执行提醒操作，而不向助手提供更改任何内容的工具。使用 Ratatoskr（开发 > AI > 默认助手）时，转录文本绝不离开本机。

说“提醒我明天 15:00 打电话”或“10 月 30 日 15:00 看牙医，提前 30 分钟提醒”。约会默认在提前一小时（或您选择的提前量）以及日程发生时提醒；普通提醒在到达设定时间时提醒。带日期但不带时间的事项在任何助手下都会打开时钟。其他缺失的详细信息或歧义内容会在终端中打开完整的编号选项列表。键入编号或您自己的回答，或使用 SUPER + D 进行听写；按 Esc 取消。通知会报告结果。也可以要求列出或取消提醒。

“新建提醒”还接受 `tomorrow 15:00`、星期名称、`2026-10-30 09:00`、`Oct 30 15:00`、`9am`、`in 5 minutes` 和 `every 29th`。在命令行中请对多词日期加引号。每个提醒都有其独立的计时器；取消操作会移除所有提醒。错过的提醒会在下次登录时显示。键入或口述没有时间的日期会打开一个小闹钟：在 HH:MM 字段中键入 24 小时制时间；按 Backspace 删除最后一位数字，方向键调整小时或分钟；按 Enter 设定时间，按 Esc 取消。

提醒通知会播放简短的声音，免打扰期间除外。日历标记日程日期；单击某一天可立即查看其提醒时间和标题。每个列出的提醒都有一个垃圾桶按钮：单击两次可删除单次提醒，对于重复提醒则可选择“仅此一项”（仅下次发生）或“全部”。

按 Escape、在其他地方单击或几秒钟内没有输入将保留提醒。

重复提醒接受 `every day 08:00`、`every Monday 09:30`、`weekdays 07:00`、`every Monday and Thursday 09:30`、`every week`、`every month on the 15th` 和 `every year`（带时间）。在 `eitr remind "every day 08:00" 伸展` 中请对整个短语加引号。助手还支持时间间隔和结束日期或发生次数。诸如 31 日等每月日期和每年的 2 月 29 日会自动后备回退到该月的最后一天。本地时钟时间和相对提醒均予保留。

仅下一次发生具有计时器；停机后会显示一次错过的发生，并跳过已过期的发生，计入限额。“即将到来的提醒”显示下次时间和规则。选择“仅本次”或“所有未来周期”以取消；命令行使用 `eitr remind cancel ID occurrence` 或 `eitr remind cancel ID series`。日历使用圆点标记发生日期，使用 ↻ 标记重复条目，保持其固定高度。

提醒通知（包括错过的提醒）在弹出窗口和通知历史中提供**推迟 5 分钟**、**推迟 10 分钟**、**推迟 1 小时**和**关闭**。推迟会从您单击的时间开始安排一个带有相同文本的独立单次提醒；重复提醒保持其原有安排。关闭操作可关闭提醒。操作保留长达 24 小时，随后通知过期。

**主菜单 > 工具 > 提醒事项 > 日历源 > 添加日历…** 在日历面板中以只读方式显示 Google、Outlook 或其他 iCal 日历，无需登录。选择提供商：Google 和 Outlook 在浏览器中打开其设置。在 Google 中，复制“我的日历的设置 > 集成日历 > iCal 格式的私密地址”；在 Outlook 中，在“设置 > 日历 > 共享日历”下发布日历并复制其 ICS 链接。

粘贴地址（`https://` 或 `webcal://`），然后命名日历。拥有该地址的任何人都可以读取日历，因此 Eitr 将其保存在私密文件中，绝不会在菜单、通知或日志中显示；如果泄漏，请在提供商处重置私密地址。日历在登录时、每 15 分钟以及打开日历面板时刷新（最多每分钟一次）。

从上周到未来 60 天内的日程显示在提醒事项旁边，附带日历名称且没有垃圾桶按钮：请在 Google 或 Outlook 中更改它们。定时日程在开始时随提醒声音发出提醒；全天日程不发出提醒。显示每日、每周、每月（日期数字或星期几，例如最后一个星期五）和每年的重复日程；较罕见的规则仅显示其第一个日程。

在“日历源”菜单中，在日历上按 Enter 立即刷新，按 Delete 在确认后将其移除。不支持双向同步（创建或编辑提供商日程）。当您在浏览器中复制链接时终端保持打开；在审核界面按 Enter 添加，按 Esc 取消。

## 插件

插件是包含脚本、Walker 行、可选视觉部件（磁贴、面板、桌面小部件和桌面栏项）以及可选一个用户服务的 Git 仓库；一个仓库可以包含多个插件。插件以您的身份运行，拥有您账户的完整权限：它可以读取您的文件、SSH 密钥和浏览器数据，将其发送到任何地方，并保持自身运行。

Eitr 未审核其代码；代码属于其作者而不属于 Eitr，每个插件行都会如此声明，例如“Ada 创作的插件 · 未经 Eitr 审核”。请仅添加来自您信任的人员和仓库的插件。

插件可以声明 `packages`：来自已启用的 Arch 官方仓库或 `[eitr]` 的最多 32 个唯一的纯软件包名称，绝不能是 AUR、URL 或本地文件。审核界面列出已安装的软件包和缺失的软件包；未知的软件包会拒绝安装。批准后，Eitr 通过系统 polkit 对话框请求管理员密码并仅安装缺失的软件包。添加软件包的更新也需要审核。移除时提供清理为该插件安装的软件包的可选操作，仅在它们仍为未使用的依赖项时执行；显式安装或另一个插件需要的软件包予以保留。

“主菜单 > 安装 > 插件 > 添加插件”提示输入 HTTPS Git URL，或者对于私有仓库输入 SSH URL（如 `git@github.com:you/plugin.git`，它通过 agent 使用您的 SSH 密钥）。添加需要两次确认，且两者默认均为“否”。首先，在下载任何内容之前，安全页面会说明这些风险；按 Enter 下载插件以供审核。

随后审核开始，附带信任警告和各项提示（每次登录时启动的后台服务、二进制文件），紧接着是清单作者、仓库、准确提交、Git 作者和日期、版本、可执行文件数量以及菜单行。按 Enter 安装；在任一步骤按 Esc 均可取消。

在批准之前，插件的任何内容都不会运行。`eitr plugin add URL` 会询问相同的两个问题（按 Enter 继续，按 Esc 取消），并且在没有终端的情况下拒绝运行。“主菜单 > 安装 > 插件 > 已安装插件”列出已安装的插件文件夹；每个已安装的插件都有一个用于其操作、视觉效果、移除和可用更新的文件夹。

在安装审核中，按 A 让您的默认助手以文本形式检查仓库的临时副本，不使用任何工具。Ratatoskr 和 Claude 可以检查插件；不受支持的默认助手会在审核中指明。Claude 将文本发送给其提供商；Ratatoskr 将其保留在本机上。

使用 PgUp/PgDn 滚动报告。AI 可能会遗漏问题：这属于建议而非批准，完整权限警告依然适用。按 Enter 安装，按 Esc 取消，包括在检查运行期间。错误、空回复和 180 秒超时仍保留常规审核可用。不会自动安装任何内容。目录还支持仅包含数据的 Git 主题包。

“Eitr Store”目录还支持在不打开终端的情况下安装和更新插件。“官方”和“社区”卡片打开详情，包含图片、视频和组件信息；“安装”打开原生提交审核。“已安装 > 从 Git 地址添加”接受 HTTPS 或 SSH。审核包括文件、命令、QML 源代码、作者和更新更改，以及可选的纯文本 AI 建议。

按 Enter 确认，按 Escape 取消。暂存的候选版本会根据其准确审核的提交进行检查；“社区”使用索引的固定版本。令牌在 15 分钟后过期，关闭目录会将其废弃。视频初始静音播放并在关闭时停止。

系统更新仅检查是否有新的插件提交（即使系统软件包已是最新），并输出数量和更新位置。它绝不审核或更新插件；网络错误会被静默忽略。从**控制中心 > 插件**（位于“添加插件”旁边）或**插件 > 更新插件**运行**更新插件**，或使用 `eitr plugin update`。

“更新插件”按钮和行仅在上一次检查发现更新时显示。插件行中的小 ↑ 标记及其详情中的“有可用更新”反映了对其已批准提交的最新检查。独立操作保留了现有的按插件 diff、风险标记和确认。

每次更新均以摘要开始：新旧提交、提交主题、更改的文件（包含添加和删除的行数），以及针对添加、更改或删除的后台服务、任何清单更改、新增或更改的可执行文件、二进制文件以及非已批准提交作者所做提交的风险 (RISK) 标记。

按 `d` 在分页器（安装了 `delta` 则使用它，否则使用 `less -R`）中阅读完整 diff，按 Enter 更新，或按 Esc 保留当前版本。当历史记录被重写导致已批准的提交不属于新提交的一部分时，Eitr 不会自动更新并说明原因；如果您依然信任该插件，请将其移除并重新添加。

非交互式更新跳过插件。“插件 > 已安装插件 > 该插件”提供“更新”和“移除”；移除会提示确认并移除其文件、菜单行和服务。相同的流程可通过 `eitr plugin list`、`eitr plugin add URL`、`eitr plugin update [ID]` 和 `eitr plugin remove ID` 使用。

Eitr 在带有签名的 `eitr-desktop` 软件包内部随附了插件阻止列表，因此 pacman 的软件包签名对其起到保护作用。每个条目均指明仓库、提交或插件 ID 以及原因。添加或更新被阻止的插件会被拒绝。已被安装但随后被阻止的插件会停止运行：其行离开“插件 > 已安装插件”，无法启动，其服务被停止并禁用，并且会有一条通知说明其名称和原因，附带“移除”按钮。

“插件 > 已安装插件”将其标记为已阻止，选择它即可将其移除。其文件绝不会自动删除。如需举报有害插件，请访问 `https://github.com/eitr-org/eitr/issues/new?template=malicious-plugin.yml`；切勿在报告中粘贴密码、令牌或密钥。组织配置文件也可以关闭插件或仅允许列出的仓库（参见“组织配置文件”）。

插件仅保存在 `$XDG_DATA_HOME/eitr/plugins/<id>/`（默认为 `~/.local/share/eitr/plugins/`）中；批准信息保存在 `$XDG_STATE_HOME/eitr/plugins.json` 中。服务使用 `$XDG_CONFIG_HOME/systemd/user/eitr-plugin-<id>.service`，带有 `NoNewPrivileges=yes`，因此它们无法通过诸如 sudo 等程序提升权限。切勿使用 sudo。更新会验证独立的候选版本，并在拒绝或失败时保留先前已批准的提交。插件在运行期间可以修改您的文件；将其移除无法撤销这些更改。

### 清单参考

版本 1：仓库根目录包含 `eitr-plugin.json`。仅接受以下键：`id`（由单个短横线分隔的小写字母/数字）、`name`、`description`（最多 72 个字符）、`author`、`version`、`rows`（1–20；声明 `ui` 时为 0–20），以及可选的 `service`、`schemaVersion`、`packages` 和 `hooks`。每行都需要 `title`、`description`（两者最多 72 个字符）和 `run`；可选的键包括 `icon` 和 `arguments`（固定字符串数组）。

服务仅接受 `run` 和可选的 `arguments`。命令使用 argv，绝不使用 shell 字符串。`run` 必须指明仓库内部的可执行文件：绝对路径和 `..` 会被拒绝，插件内部任何位置的符号链接也是如此。未知或重复的 JSON 键会被拒绝。子模块不会被初始化。

`distro/plugins/example/` 中的微型示例包含一个清单和 `notify.sh`、一个通知操作、一个主题钩子，没有服务。将其复制到您自己的 Git 仓库中，提交它并发布 HTTPS Git URL 即可体验完整的安装流程。该示例作为文档随附；它不会自动安装。对于视觉插件，`https://github.com/eitr-org/eitr-plugins` 的官方集合包含 Visualizer。

对于仅包含脚本的清单声明 `schemaVersion: 1`，对于下述可选的 `ui` 部分声明 `schemaVersion: 2`。没有版本的较早清单仍可作为 v1 工作，在审核中会有提示；高于 2 的版本需要更新的 Eitr。作者指南 `distro/PLUGINS.md`（打包为 `PLUGINS.md`）定义了稳定的版本 1 规范。

插件可以声明 `theme-changed`、`wallpaper-changed`、`after-update` 和 `login` 钩子。它们在操作后在后台运行（登录钩子每个桌面会话运行一次），具有 30 秒的超时时间。故障记录在 `$XDG_STATE_HOME/eitr/plugin-hooks.log` 中，绝不会导致操作失败。审核界面列出钩子；新增或更改的钩子会引发更新风险 (RISK) 标记。阻止列表和组织策略同样适用于钩子。

### 视觉插件

架构版本 2 可以向**控制中心 > 通用 > 插件**添加磁贴，以及从这些磁贴打开的面板。它们可以遵循 Eitr 的颜色、字体和圆角；桌面栏项在插件安装后放置在桌面栏上，小部件在您添加后显示。审核界面在安装前列出每个 QML 文件及其完整源代码。更新在批准前显示可滚动的 diff 和候选 QML；QML 更改会引发风险 (RISK) 标记。QML 不是沙盒：它在桌面栏内部以您的完整权限运行。请信任作者；加载器无法对循环或原生崩溃进行隔离。

组件加载错误会显示内联错误而非其内容，并记录在 `$XDG_STATE_HOME/eitr/plugin-ui.log` 中。在出现三次加载或报告的错误后，该插件的视觉组件将被禁用，跨更新依然保持禁用。在“控制中心 > 插件”中选择**重新启用**，或运行 `eitr plugin enable-ui ID`。在达到阈值之前，关闭并重新打开“通用”可重试。

菜单行、钩子和服务是相互独立的。插件出现在现有“通用”部分之后。面板替换磁贴，带有标题和返回尖括号；按“返回”或 Escape 返回磁贴，然后再次按 Escape 关闭控制中心。较高的面板在子视图内部滚动。架构 v2 示例具有一个 Hello 磁贴和状态面板。

架构 v1 插件继续保持受支持且不变。创作详情和精简的样式/数据 API 位于 `distro/PLUGINS.md` 中；该 API 是受支持的接口，而不是安全边界。

### 插件管理器与小部件选项

**控制中心 > 插件**列出每个已安装的插件及其图标、作者、版本、说明和启用状态。展开“预览”可查看其屏幕截图。“启用/禁用”保留布局位置，并停止或恢复服务、Walker 行、钩子和视觉效果；命令行操作为 `eitr plugin enable ID` 或 `eitr plugin disable ID`。“添加插件”、“更新”和“移除”打开经过审核的终端流程；移除会提示确认。“通用”仅保留插件磁贴。视觉故障具有独立的“重新启用”操作。

您可以根据需要随意向显示器添加小部件：每个副本都保留其自己的显示器、位置、大小、旋转和设置。在多显示器环境下，“添加”会询问针对哪台显示器，优先列出当前聚焦的显示器。“移除”会隐藏桌面栏项，且更新会使其保持隐藏。“编辑位置”暂时将副本提升到窗口上方：拖动其标题或调整大小手柄，然后单击“完成”或按 Escape。移动是连续的；松开后贴合到桌面间距并保存。Plugins 页面中每个副本的卡片及其右键菜单（在窗口后方的小部件上，或编辑模式下的任何小部件上）提供相同的设置：“编辑位置”、“复制”（在显示器左上方新建副本）、尺寸步进（90% / 110%，在屏幕限制内保持宽高比和中心）、“全宽”、“旋转”（在 3° 内贴合到四分之一转的滑块、45° 旋转和重置）、“显示器”（移动保留大小和设置）、“面板/透明背景”、“置于窗口上方”、插件选项和“从桌面移除”。

“全宽”在保持相同宽高比的情况下适应最大尺寸。“置于窗口上方”的小部件支持穿透点击；请在“插件”页面中使用其选项。在该页面或“Walker 视觉效果”中选择“编辑小部件”可切换所有小部件为可交互状态，直到单击“完成”或按 Escape（`plugin-widgets edit` / `done` IPC）。缺失的显示器会保留其保存的布局。

透明背景没有宿主颜色、边框或模糊；编辑手柄保持可见。新的架构 v2 插件需要正方形 PNG/SVG 图标（最多 512 KiB，PNG 64–1024 px）；可选的预览图为 PNG/JPEG，每轴最多 2 MiB 和 3840 px，主页为 HTTPS。现有的无图标插件使用通用图标并在审核中附带说明。作者 API 增加了 `api.setMenu([{id, text, checked, group}])` 和 `api.menuTriggered(id)` 用于类似“波形/跳动条”等选项。有关验证和 API 详细信息，请参阅 `distro/PLUGINS.md`。

架构 v2 插件可以请求 `audio-spectrum`。审核说明它仅读取系统音频电平：不录制或发送任何音频，宿主也绝不捕获麦克风。添加此功能会引发风险 (RISK) 标记。所有可见的使用方共享一个播放频谱提供程序；插件请求 8–128 个跳动条和高达每秒 60 帧。

当没有可见的使用方时它会停止。声明的 `dataStream` 命令在其组件可见时传递实时文本行，限制为每秒 60 行且每行 4096 字节。审核界面会列出它，更改会引发风险 (RISK) 标记。隐藏的组件会停止其数据流和子进程组；故障时通过退避重试。

创作详情在 `distro/PLUGINS.md` 中。

插件作者自行选择其颜色、图像、着色器和动画。主题辅助工具（`api.palette`、color0–15 和具名角色、字体、尺寸、圆角和 `themeChanged`）是可选的。小部件和面板默认为 `surface: "none"`；`"panel"` 选择使用 Eitr 的背景。显式保存的小部件背景会覆盖声明；否则应用声明。控制中心保留其外层页面边框，而在插件画布内部不添加额外装饰。

面板保留导航标题栏，除非设置了 `header: false`；“返回”/Escape 仍可正常工作。磁贴默认为 `look: "eitr"`；`"custom"` 绘制整个固定槽位，仅保留宿主激活和焦点环。桌面栏槽位不添加悬停填充或淡色。相对 QML 图像在插件目录中解析。边界、居中时钟、审核、功能和故障处理保持不变。
