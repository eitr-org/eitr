# 欢迎使用 Eitr

您的全新桌面已就绪。浏览简短导览，配置基础设置，然后尽情打造属于您的个性化桌面。

<!-- eitr-welcome:tour -->
## 快速导览

- **桌面栏**: 工作区、时钟和状态图标位于屏幕边缘。点击图标可打开相应控制；空闲锁定可直接切换自动锁定。
- **启动器**: 按 **SUPER + Space** 查找应用，或按 **SUPER + F** 浏览所有菜单。直接键入即可搜索，然后按 Enter。
- **设置**: 按 **SUPER + ,** 打开显示器、声音、键盘、外观等设置。所有设置页面均支持搜索。
- **控制中心**: 按 **SUPER + I** 开启快捷开关、屏幕截图以及与助手的快速对话。
- **主题**: 主题为整个桌面提供统一步调的色彩，并附带专属壁纸。您可以随时切换，或创建自己的主题。

## 配置基础设置

在桌面上，以下各项都会在“设置”中打开对应的页面。

- **Wi-Fi**: 连接到网络。
- **主题与壁纸**: 选择您每天都想看到的色彩与艺术作品。
- **键盘**: 添加、排序和切换您的键盘布局。
- **个人资料头像**: 选择账户显示的头像图片。
- **显示器**: 设置每个已连接屏幕的分辨率与缩放比例。
<!-- /eitr-welcome:setup -->

## 温馨提示

**SUPER** 是 Windows 或 Command 徽标键。**SUPER + Enter** 可打开终端。桌面栏右侧的图标可能处于折叠隐藏状态：点击箭头即可展开显示。全新安装默认使用 **Eitr** 主题和 **Eitr** 锁屏；现有桌面则保留您的个人选择。

此欢迎界面会在首次登录时自动打开。开启**在下次登录时显示此欢迎界面**可再次查看，或者通过**学习 > EITR 用户手册**或快捷键 **SUPER + F1** 重新打开。

**程序出现故障时提示报告问题**默认开启，并与“崩溃通知”设置共享：当程序发生崩溃时，通知会提供协助或生成供您审查后再发送的错误报告。详情请参阅[故障排除](handbook:troubleshooting)。

## 按您自己的节奏学习

搜索功能可查找章节标题和正文文本：**Ctrl + F** 聚焦搜索栏，Up/Down 选择匹配项，按 Enter 打开。**Page Up/Page Down** 滚动页面，**Ctrl + Home/End** 跳至开头或结尾，**Alt + Left/Right** 在章节间切换（如同“上一章”与“下一章”）。Escape、关闭按钮或快捷键均可关闭窗口；在窗口外部点击不会关闭。

用户手册绝不会自动执行命令。代码块仅供仔细阅读和手动复制参考，外部链接仅在您主动点击时才会打开。继续阅读[快捷键](handbook:shortcuts)、[桌面栏](handbook:desktop-bar)或[设置](handbook:system)。

## Eitr 包含的内容

Eitr 将 Arch Linux 与 Hyprland 结合，围绕 Walker 的可搜索菜单和 Quickshell 栏打造桌面环境。您可以选择 Full、Centered、Tabs、Islands、Dynamic 或 Drop 布局；面板整合了连通性、音频、显示器、硬件、通知、天气和工作区。主题统领桌面风格，您也可以创建自己的个性化主题。

系统更新可统一处理官方源、AUR 和 Flatpak 更新，并在受支持的发行版安装上提供快照保护。引导防护机制能够在登录前恢复失败的更新。恢复出厂设置需要受支持的安装环境及其首次登录基准、警告提示以及键盘键入确认。安装程序支持离线软件包安装；恢复和安装均依赖文档记录的受支持布局。

Steam 已预装并集成了 GameMode、MangoHud 和 gamescope；“安装 > 游戏”提供更多游戏工具。具备 HDR 能力的显示器将显示 HDR 控制选项；已安装游戏客户端或 HDR 显示器并不保证所有游戏均能正常运行。开发菜单提供编辑器、运行时、Docker 和 AI 助手。Git 账户按文件夹隔离身份；云菜单保持提供商上下文清晰可见。各项功能的可用性取决于系统的具体安装与配置情况。

日历和提醒事项有助于规划日程。配置完成后，听写功能可将语音转换为文字。远程访问工具包括 Moonlight 和 Sunshine；根据需要安装并配置所需工具。插件可通过插件工作流扩展 Eitr 的功能。桌面翻译支持英语、巴西葡萄牙语、西班牙语、法语和德语。离线用户手册详细解释了快捷键、设置、配置和恢复操作，绝不会向外界发送您的任何查询。控制中心的快速对话使用您选择的助手，并发送对话内容、受限的机器摘要和手册上下文；它无法执行命令或修改设置。
