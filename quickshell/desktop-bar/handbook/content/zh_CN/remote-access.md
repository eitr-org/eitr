# 远程访问

打开“设置 > 串流”可管理 Sunshine 和 Moonlight，Walker > 设置 > 设备 > 串流 亦提供相同的操作。主机共享功能默认保持关闭，直至您主动开启。本阶段用于控制已登录且处于唤醒状态的 Eitr 桌面。无显示器 (headless) 使用、登录前访问以及网络唤醒 (Wake on LAN) 属于后续独立开发内容。在共享期间，若本机锁屏，远端屏幕亦会显示锁屏界面；任何已连接的人都可以看到锁屏并输入密码，因此在涉及隐私的场合离开电脑前请务必停止共享。

设置文件夹对配置操作进行了归类归组。“串流 > 共享设置”包含“设置共享”、“共享设置”、“登录时自动启动”、“关闭登录时自动启动”、“详细状态”以及“还原共享设置”。日常共享操作（开启共享、停止共享、配对设备、共享状态以及连接到另一台电脑）直接位于“串流”主菜单中。

“详细状态”会打开一个诊断终端，直到您按 Esc 键才会关闭。

## 在 Eitr 上运行 Sunshine

选择“共享此电脑 > 设置 > 设置共享”。安装使用的是由发行版维护者从上游源码编译并签名的 Eitr 原生 Sunshine 软件包。首次点击不会触发本地 AUR 构建。Flatpak 和 AppImage 缺乏 KMS 捕获能力。现有的 Sunshine 配置和已配对设备将得到保留；切勿同时运行多个 Sunshine 实例。

请仔细阅读完全控制警告，仅在您接受 KMS 屏幕捕获以及虚拟键盘、鼠标和控制器输入的前提下键入 `yes`。设置向导会将原始权限私密保存在 `/var/lib/eitr/remote-access` 中。它会添加 uinput udev 规则，在引导时加载 uinput，授予桌面用户设备访问权限，并赋予 Sunshine `cap_sys_admin+p` 权能。这些都是非常强大的系统权限。

“还原共享设置”会停止共享，恢复已保存的文件和设备 ACL，并移除捕获权限。如果向导先前加载了 uinput，撤销操作也会将其卸载。如果仍有其他应用程序在使用它，撤销操作会报告失败并保留日志，以便您关闭该应用后重试。

“开启共享”在授予远端设备控制权之前会进行确认。本地 Web 设置地址为 `https://localhost:47990`。初次使用时，在您设置密码期间串流将保持阻止状态。返回终端确认密码已设置；随后您的管理员密码将启用远程控制。请仅在该本地地址接受自签名证书。

在配对之前，请先设置 Sunshine 的用户名和高强度密码。向导中的“共享设置”可回到此处；“配对设备”可打开 PIN 码输入页面。请仅输入您自己的 Moonlight 设备上显示的 PIN 码。请保持路由器自动配置关闭；Eitr 强制要求 `upnp=off`。请勿在路由器上配置端口转发。

TCP 47984、47989、48010 以及 UDP 47998-48000 仅允许来自直接连接的本地局域网私有子网。TCP 47990 仅限本机访问，即使其他防火墙规则允许也会受到限制。每次启动时都会重新捕获局域网范围；在切换网络后请停止并重新开启共享。请仅使用受信任的家庭网络。

“停止共享”还会禁用登录时自动启动并关闭串流端口，包括已建立的串流连接。服务崩溃故障同样会关闭它们；运行时开放的端口不会在重启后保留。首次配置完成后，“开启共享”和“停止共享”可即时切换，无需额外提问或输入密码。“登录时自动启动”是可选功能，可直接从串流面板或菜单即时切换；“关闭登录时自动启动”则保持手动开启共享。

“共享状态”会显示服务错误信息。

Sunshine 软件包更新会替换可执行文件，从而清除其捕获权能；随后更新机制会将其重新赋予当初配置共享的账户。如果共享依然无法启动，串流开关会说明原因：重新运行“设置共享”，或在首次配置后注销并重新登录。原始撤销记录会予以保留。

Sunshine 仅能以 root 或共享账户身份运行并获得 KMS 权能：设置向导将可执行文件设置为 `root:eitr-sharing` 权限模式 `0750`，并将您的账户添加到该系统用户组中。在开启共享前请先注销并重新登录，以便用户服务接收新的用户组权限。向导会保持正在运行的共享进程处于活动状态；在下次登录前直接重启可能会失败。

“停止共享”会保留向导配置的系统权限。“还原共享设置”会移除用户组成员资格及所有二进制权能，并将可执行文件恢复为 `root:root` 模式 `0755`，还原旧设置记录时亦同。软件包更新后，“设置共享”会在重新授予权能前修复文件归属与权限模式。

## 在 Mac 上使用 Moonlight

从 [Moonlight 项目官网](https://moonlight-stream.org/) 安装 Moonlight。首次测试请确保 Eitr 和 Mac 处于同一家庭网络中。如果自动发现未能找到电脑，可手动添加 Eitr 的局域网 IP 地址。选择该电脑，记下其 PIN 码，然后在 Eitr 上使用“配对设备”。选择 Desktop 即可控制应用程序和游戏。Sunshine 设置中可选择被捕获的显示器；请对每个显示器单独进行验证。“游戏 > Moonlight”和“连接到另一台电脑”可安装或打开 Eitr 客户端以实现反向连接。全新安装包含这些应用；共享功能默认保持关闭，直至显式启用。

Mac 上的 SUPER 快捷键：在 Moonlight 设置中开启**捕获系统键盘快捷键**（在全屏模式下或始终开启）。只有这样 Moonlight 才会将 Mac 的 Command 键作为 SUPER 发送；否则 Command 快捷键仍由 Mac 本地捕获。在会话期间可使用 Ctrl+Alt+Shift+K 开启或关闭该捕获功能。

## 测试验证情况

自动化测试采用模拟环境 (mocks)。在搭配运行 Moonlight 的 MacBook 的真实物理桌面（单显示器及双显示器）上验证了：配置、开启共享、按 IP 地址配对、视频、键盘、鼠标、音频、锁屏（从 Mac 成功解锁）、登录时自动启动、在家庭网络内及外出通过 VPN 停止共享和还原共享设置。手柄控制器、其他品牌 GPU 及其他客户端尚未经过全面测试。

“串流”位于“设备”下的“连接”旁。Sunshine 显示共享状态、设置、开启/停止、登录时自动启动、配对、设置选项、诊断及还原设置。Moonlight 显示安装状态以及“安装/打开”按钮。
