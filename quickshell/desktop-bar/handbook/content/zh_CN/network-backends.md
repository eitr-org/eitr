# 网络后端

“设置 > 连接 > Wi-Fi > WiFi 后端”可选择 iwd（全新安装默认值）或带 wpa_supplicant 的 NetworkManager。两者均使用 systemd-resolved 进行 DNS 解析。共用的 WiFi 面板检测的是当前正在运行的后端，而非保存的下次启动选择。当前连接不会被强制重启：属于 root 的辅助程序准备好相关文件并启用/禁用开机服务（不带 `--now` 参数），然后询问是否立即重启。若拒绝，该选择将加入队列直至下次重启时生效。

已保存的 WiFi 配置文件保留在各自后端的独立存储中。它们不会被删除或自动转换；首次切换时需重新连接，切回原后端时可复用旧配置文件。切换前请检查自定义静态 IP、VPN、网桥、networkd 文件或其他网络管理器。如果存在被屏蔽的服务、另一个处于活动状态的管理器或自定义解析器，系统会拒绝切换而不是静默替换。原始托管文件和服务启用状态私密保存在 `/var/lib/eitr/network-backend` 下；“恢复原始网络配置”可在下次引导时恢复它们，而无需停止当前网络。

`eitr-desktop` 软件包包含两个后端以及 root 所有的辅助程序 `/usr/lib/eitr/eitr-network`；请安装该软件包而非手动复制辅助程序（详见发行版 README）。先前手动安装的辅助程序会阻止软件包安装，直至 `distro/system/adopt-unowned-files.sh --apply` 将其归档。切勿从用户可写路径提升辅助程序权限。安装辅助程序本身不会自动选择后端。

## 企业级 WiFi

面板支持 PEAP/MSCHAPv2 和 TTLS/PAP，包含用户名、可选匿名身份、密码、身份验证服务器域名和 PEM CA 证书路径。请向网络管理员索取这些配置参数。服务器证书验证是强制性的；EAP-TLS/客户端证书、SIM/AKA 及其他高级验证方法仍需要外部配置。Impala 仍作为此类配置的可选回退项；请勿仅因支持常见方法就将其移除。

凭据通过进程标准输入和 D-Bus 传递，绝不作为命令行参数传递。NetworkManager 保存其常规连接配置文件；iwd 配置使用 PolicyKit 身份验证以及嵌入了 CA 的私有 root 所属 `.8021x` 配置文件。现有的企业配置文件不会被自动覆盖：在替换配置文件之前必须显式“忘记”该配置文件。系统仅接受 root 所有且非组/全局可写的辅助程序。自动化测试不会执行真正的后端切换、WiFi 连接或企业身份验证；在声称经过硬件验证前，请在备用硬件或隔离虚拟机上进行验证。
