# 信息、媒体与通知

通知卡片会在标题下方显示其本地到达日期和时间，弹窗和通知历史记录中均是如此。时间仅保留在当前会话中。

## 查看系统信息

打开“设置 > 关于”可查看 Eitr 版本、代号、更新通道、内核与许可证，以及本台电脑的处理器、显卡、主板、已安装内存和每个已连接驱动器及其容量。“系统”概览显示您的个人资料、当前硬件使用率和网络速率（下载和上传）。如需详细的硬件信息、AI 用量和天气，请点击它们各自的桌面栏图标；Walker 亦可通过名称找到它们。

在“设置 > 关于”中，在“关于页面徽标”下选择“徽标”或“符文”，可更改终端“关于”页面。该选择保存在本机上，默认选用“徽标”；两者均跟随当前主题强调色。

**硬件**显示 CPU、GPU、RAM 以及挂载 `/` 根分区的驱动器的存储占用情况；其他磁盘不会合并计入该总数中。缺失的传感器或 GPU 遥测数据会标记为不可用。

**AI 用量**会自动检测已安装/配置的客户端。缓存的用量优先显示；刷新不会发起登录或对话。它会显示每个账户的额度限制；百分比表示已消耗的额度比例。Claude、Codex、Grok 和 Antigravity 具有可读取的套餐限制（Antigravity 按模型分组：Gemini、Claude 与 GPT 以及 Argon）；按用量付费的助手（如 Copilot CLI、OpenCode、Pi 或带 API 密钥的 Gemini CLI）则无相关条目。

每个检测到的提供商都有其专属区域，显示其套餐、限制与错误。点击标题可仅展开或折叠该区域。各区域在登录时默认折叠，并在当前会话期间保持展开或折叠状态。长列表可在屏幕范围内滚动。

**天气**使用默认位置并支持临时搜索城市。城市覆盖在面板关闭时结束。关闭前面板按 Escape 会先清除城市搜索；温度单位跟随所选位置，并在旁边标注备选单位。

## 日历与媒体

点击时钟/日期可打开日历。它保留六周视图，并在网格下方显示年度进度。可使用上一月/下一月按钮、“今天”、方向键或 T 键进行导航。如果栏处于隐藏状态，可从 Walker 中搜索“日历”。点击某一天可在网格下方查看当天的提醒事项；日期旁的 + 号可就地展开其日程安排，并提供输入框供添加当天特定时间的提醒，返回箭头可退回月视图。

点击动态均衡器可打开媒体面板：包含伴随音乐律动的柱状图环绕的封面、歌曲信息、歌词、上一首/播放/下一首以及受支持时的进度跳转。未运行合规播放器时该面板会自动隐藏，并排除已识别的会议。桌面栏的均衡器仅在播放中且栏条可见时，通过私有的 cava 进程实时跟踪系统音频。向左拖动均衡器可将其替换为正在演唱的歌词；向任一方向拖动歌词行可切回均衡器；暂停或切换歌曲均会保持该显示状态。在线歌词属于桌面栏设置（详见“桌面栏”章节）。

## 通知

按 **SUPER + N** 或点击铃铛图标可打开通知中心。通知按应用程序分组归纳。最新的卡片位于堆叠的最前面；展开它可查看较早的卡片。您可以单独关闭某张卡片，或刻意清除某个分组乃至全部通知。弹窗同样按应用堆叠，在底层卡片上方展示最新消息；鼠标悬停可暂停其过期倒计时。

**SUPER + Alt + N** 执行最新通知的主要操作（即点击它所触发的操作），**SUPER + Alt + Shift + N** 可将其关闭。重复收到的通知（同一应用、标题和文本）会替换先前的通知，并显示诸如 ×3 的计数，而不是额外堆叠一张卡片。

点击通知可执行其主要操作。无特定操作的通知会打开发送它的应用：打开其窗口，对于 herdr 则是切换到运行 herdr 的终端，并跳转至通知指明的工作区和标签页。每张卡片在应用自带图标时优先显示其图标，否则显示铃铛。

通知弹窗默认在每个显示器上显示。在“设置 > 通知”中关闭“在每个显示器上显示弹窗”，可使其仅在主显示器上展示。该页面同样提供“请勿打扰”和“崩溃通知”选项。
