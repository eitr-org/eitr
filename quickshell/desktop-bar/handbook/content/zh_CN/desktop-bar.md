# 桌面栏与工作区

<!-- eitr-figure: bar-anatomy -->

完整栏。Eitr 图标打开控制中心；概览、工作区标记、AI 使用量、硬件和空闲锁定紧随其后。日期和时间居中显示，媒体在其前方，天气在其后方。**显示图标**展开或隐藏右侧的状态图标；通知排在最后。

插件项目可放在自动锁定之后、时钟之前、时钟之后或状态组中。在设置 > 插件 > 对应插件 > 在栏上选择位置。按放置顺序，自动锁定之后最多4个，时钟两侧各2个，状态组最多8个；超出的项目在所选位置保持隐藏。Centered 和 Dynamic 展开时显示，Tabs 和 Islands 包含这些项目，Drop 隐藏栏上的插件项目。时钟始终保持屏幕居中。World clock 是可选的官方插件，遵循栏的12/24小时设置。

Weather 是官方内置插件，默认安装在时钟之后。在 Eitr Store > 插件 > 已安装中移除后，所有位置的天气都会隐藏，包括 Drop 主页。更新后也不会重新添加；可从“发现”使用包内副本重新安装，无需下载。城市搜索的选择仅在当前会话有效。

在“设置 > 窗口”中，“窗口布局”和“显示器”使用双按钮选项。“工作区数量”和“始终显示”使用下拉列表；“始终显示”提供从 2 到当前工作区数量的选项。每项设置下方的描述说明了其效果，包括所选的窗口布局和滚动选项。

## 更新

通知前方的更新图标在登录不久后以及每六小时检查一次。单击可运行系统更新；右键单击可重新检查。成功的系统更新会将其标记为最新状态，直到下一次检查，不会立即启动另一次检查。离线或失败的检查显示不可用状态，绝不会错误地显示“已是最新”。该检查使用独立的专用软件包数据库，不会升级软件包。

## 更改栏布局

- 双击**空白栏区域**可循环切换“主题颜色”→“模糊”→“网站”（全新安装以“主题颜色”启动）。“网站”使用 Eitr 网站的颜色，随主题呈浅色或深色。
- 双击右键空白区域可循环切换“完整”→“居中”→“标签页”→“岛屿”→“动态”→“下拉”→“完整”。
- 将空白区域拖向屏幕顶部、底部、左侧或右侧即可移动栏。左侧和右侧栏与顶部和底部栏一样轻薄：时钟在分钟上方显示小时并带有日历图标，天气显示其图标；悬停可查看日期和温度。
- “设置 > 桌面栏”下的**时钟**在每个栏边缘显示带有上午/下午的 12 小时制（默认）或 24 小时制时间。
- 相同的设置位于**设置 > 桌面栏**的“布局”、“外观”和“行为”标签页中。
- **显示器**（显示位置）将栏设置为仅在主显示器显示（默认），或在所有显示器上显示。在所有显示器上显示栏时，每个栏标记其自身屏幕上显示的工作区，快捷键（如 SUPER + I）在当前使用的显示器上打开，并且通知仅在主显示器上弹出。在“显示”面板中选择主显示器。

<!-- eitr-figure: bar-layouts -->

六种布局按双击右键循环的顺序排列。静止时，“居中”仅显示时钟，“动态”显示三个小岛，而“下拉”显示单个时间胶囊；“居中”和“动态”在悬停时展开。

在“设置 > 桌面栏”中选择布局。所有六种布局在每个屏幕边缘均可使用。

| 布局 | 特性说明 |
| :--- | :--- |
| 完整 | “完整”将整个栏保留在屏幕边缘。面板与栏连接。 |
| 居中 | “居中”仅显示时钟，直到悬停为止。使用固定图钉，或“设置 > 桌面栏”（也在 Walker 中）下的“保持展开”使其保持展开；面板浮动在其身旁。 |
| 标签页 | “标签页”使用由细条连接的三个标签页。状态图标和天气保持可见。 |
| 岛屿 | “岛屿”为每个组提供独立的胶囊，所有状态图标始终显示。打开面板会展开对应的胶囊并将其邻近组移开。 |
| 动态 | “动态”最初包含三个岛屿：图标、时钟和网络/电池，播放内容时在图标和时钟之间添加媒体岛。悬停其中一个可将其展开；打开面板会将该岛屿展开为面板。 |
| 下拉 | “下拉”仅在屏幕边缘中心的一个胶囊中显示时间。单击可展开仪表盘；右键单击直接进入快捷控制。启用自动隐藏后，屏幕上不保留任何内容，直到水滴从边缘落下并膨胀为胶囊。 |

**岛屿样式**（设置 > 桌面栏 > 布局，或 Walker > 设置 > 桌面 > 桌面栏 > 岛屿样式）决定岛屿、动态和下拉布局如何与屏幕边缘相接：悬浮会让胶囊与边缘相隔外边距的一半；贴合则让它们贴住边缘，靠边一侧为直角、两侧为直边，面板也从边缘展开。**侧边样式**决定标签页和居中布局如何与边缘相接：45° 斜坡或直边（使用直边时，标签页之间的细条也会去掉）。

## 下拉仪表盘

单击下拉的时间胶囊，胶囊本身会展开为仪表盘。横向拖动页面（向右翻页，向左返回，支持循环切换），或使用方向键或水平滚动。按 Esc 或在外部单击可将其关闭。上面的内容不会打开另一个面板：详情在原地展开，带有返回箭头。

| 页面 | 包含内容 |
| :--- | :--- |
| 日历与天气 | 月份旁边的天气。单击天气可查看完整天气预报和城市搜索；单击日期可查看其日程安排并添加当天某个时间的提醒。 |
| 媒体 | 封面周围环绕跟随音乐跳动的声波条、歌曲、歌词、播放控件和进度条。在播放内容时显示。 |
| OBS | 录制和直播状态，带有暂停、停止和开始推流按钮、章节标记、录制文件夹以及 OBS 本身。在 OBS 运行时显示。 |
| 快捷控制 | WiFi、蓝牙、声音和麦克风在原地打开其网络和设备；飞行模式、静音、夜览、空闲锁定、录制和设置；音量、麦克风和（在笔记本电脑上）亮度。 |
| 计时器与专注 | 倒计时、秒表或带有 5 分钟休息的 25 分钟专注时段。在仪表盘关闭时仍保持运行并在结束时发出通知。 |
| 性能、AI 使用量与通知 | CPU、GPU、内存和存储空间；各个助手的额度限制（单击一个可查看全部）；通知列表。 |

在每种布局中，时钟在录制红点所在的位置旁显示当前状态：当日程在十分钟内开始时显示日历标记（单击可查看当天日程），在计时器或专注时段运行时显示圆环（单击可打开“控制中心 > 工具 > 计时器与专注”）。新通知使栏上的铃铛响动两次；在铃铛隐藏的场合（收起时的“居中”，静止时的“动态”），铃铛会滑出到时钟身旁。笔记本电脑电池在 15% 和 5% 时以红色百分比短暂替换时间；在工作区隐藏的场合，切换到的工作区数字也会短暂替换时间。

在下拉胶囊的时间周围显示正在发生的状态，仅在需要时占用空间。时间前方：录制时显示红点，日程在十分钟内开始时显示日历标记，计时器运行时显示圆环，栏检查更新时显示旋转箭头，有更新通知时显示更新标记（单击可进行“系统更新”），播放音乐时显示音符（单击可打开“媒体”）。时间后方：新通知发出时响动两次的铃铛（单击可打开列表）。切换工作区时会短暂以工作区编号替换时间；笔记本电脑电池在 15% 和 5% 时以红色执行相同操作。向右拖动音符可将胶囊变为单行歌词；向任意方向拖动、暂停或停止即可恢复原状。

**在线歌词**（设置 > 桌面栏 > 行为，或 Walker > 设置 > 桌面 > 桌面栏 > 在线歌词）默认关闭。开启后，下拉面板会在 LRCLIB (lrclib.net) 上查找播放的歌曲，发送其标题、艺术家、专辑和时长。播放器自身发送的歌词始终优先使用。

## 工作区

“设置 > 窗口 > 工作区”（也在“Walker > 设置 > 桌面 > 窗口 > 工作区”）用于选择**显示器**、**工作区数量**（5–10，默认 10）和**始终显示**（2 到最大数量，默认 5）。**共享编号**（默认）为每台显示器提供其独立的 1…N：SUPER+k 一同切换所有显示器，SUPER+Shift+k 移动窗口在其当前显示器上的位置，所有显示器随之切换到该编号。**跨显示器拆分**将 N 平均分配，主显示器排在最前并优先分配余数；其他显示器按从左到右、然后按名称排列。SUPER+k 聚焦所属显示器。高于 N 的数字键无效。标记底线相对于每台显示器的范围；较高的标记会在切换到当前或最高占用的工作区时显示，不再需要时消失。连接或移除显示器以及更改主显示器会重新计算分配而不会丢失窗口；窗口移动到其当前显示器上最近的有效编号。单显示器在两种模式下保持相同的行为。
右键单击标记可选择“圆点”、“字形”、“数字”或“符文”，并带有实时示例。
所有四种选项均适合在各个栏边缘的弹出窗口中显示，无需滚动。
“符文”为默认设置。活动标记使用强调色字形，没有实心填充背景。
“符文”将工作区 1 到 10 显示为前十个古弗萨克符文（ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ ᚷ ᚹ ᚺ ᚾ）。

**SUPER + 1–9/0** 切换工作区；**SUPER + Shift + 1–9/0** 移动窗口。
**SUPER + Tab** 打开概览。单击预览或使用方向键和 Enter；1–9/0 直接切换。仅显示已占用的编号工作区，且其预览保存在内存中。按 Escape 或在外部单击可关闭概览。

**SUPER + S** 切换特殊工作区，该工作区与概览相互独立。
**SUPER + Shift + 空格键** 开启或关闭桌面栏的自动隐藏；如果桌面栏之前已从控制中心隐藏，则会先恢复显示。通知在两种情况下均正常运作。

在空白桌面空间上，壁纸/主题鼠标手势列在**学习 > 鼠标手势**下。有疑问时请使用键盘轮播快捷键。

音频/麦克风控件打开一个面板，其中包含独立的输出和麦克风部分。推流紧邻 OBS 前方。标题栏中的开关用于启动屏幕共享，随后显示详细信息，设置或诊断操作位于“…”菜单中。图标按钮在悬停时显示其背景；面板在打开时自行刷新，刷新图标仅在加载时旋转，提示框显示在指针附近。开关和内嵌操作按钮采用紧凑的通用尺寸。

**音乐可视化工具**打开带有主题颜色的 cava。右键单击媒体均衡器可打开相同的可视化工具；左键单击仍会打开媒体详情。按 **q** 或 **Esc** 可将其关闭。在现有桌面上，如果缺少 cava 软件包，会优先安装。

“设置 > 桌面栏”下的**自动隐藏**在指针离开短暂延迟后滑走桌面栏。轻触其屏幕边缘即可显示。它适用于所有四个边缘以及“完整”、“居中”、“标签页”、“岛屿”、“动态”和“下拉”布局；在“下拉”模式下，带有桌面栏颜色的水滴从边缘落下并膨胀为时间胶囊。新通知会唤出桌面栏，直到其弹出窗口关闭。打开面板和弹出窗口以及拖动桌面栏会使其保持可见；之后会重新隐藏。开启自动隐藏时，桌面栏不预留窗口空间：它滑在窗口上方而不是移动窗口。该设置独立于居中布局图钉保存，在全新安装中默认关闭。

“设置 > 桌面栏”下的**减少动画效果**使面板展开和折叠、概览进入动画、通知过渡和装饰性栏动画瞬间完成。默认关闭并保存在 `bar-settings.json` 中。刷新数据、关闭通知或延迟自动隐藏的计时器保持其正常行为。

媒体样式保存在 `bar-settings.json` 中：在“设置 > 桌面栏”下选择“跳动条”（默认，十个跳动条）或“波形”（简单的平滑音频声波）。指示器位于播放控件前方，在每种布局中保持固定大小并在左/右边缘旋转。悬停可查看歌曲名称；左键单击打开媒体详情，右键单击打开音乐可视化工具。向左拖动可在其位置显示单行歌词；向任意方向拖动歌词行可恢复原状。暂停播放会使波形平滑归零。“减少动画效果”保留实时音频电平而不使用缓动效果，并停止装饰性后备动画。

## 边缘快捷栏

轻触桌面栏对面的屏幕边缘可显示应用程序快捷栏（Dock）。它从该边缘展开，平直边与屏幕边缘贴合，覆盖在窗口上方而不移动或调整窗口大小，并在指针离开 350 毫秒后隐藏，采用通用的 320 毫秒动画（在“减少动画效果”下为瞬时动画）。它显示在主屏幕上，当“显示器”设置为全部时显示在每台屏幕上，绝不会在全屏窗口上方显示。

快捷栏首先显示固定应用，随后按 Hyprland 的窗口顺序显示其他打开的应用程序。每个 36 px 的图标槽位具有 6 px 间隙并使用应用程序的桌面图标，带有字形后备；Eitr 自身的任务和菜单终端共用一个 Eitr 图标。图标下方的圆点计算其窗口数量（最多三个），当该屏幕的当前工作区上没有该应用窗口时变暗。

悬停可查看其名称和窗口数量；指针附近的图标会放大，最近的图标放大最明显，快捷栏随之变长以容纳图标，除非开启了**减少动画效果**。单击可聚焦其最近使用的窗口（包括切换工作区）；再次单击可切换到其下一个窗口。中键单击关闭最近使用的窗口。

长列表沿快捷栏滚动。表面遵循“模糊”/“主题颜色”和圆角偏好。

**设置 > 桌面栏**中的**快捷栏**用于开启或关闭它。`bar-settings.json` 中的 `dock` 设置默认为 `"yes"`。快捷栏没有快捷键。

固定应用关闭时保持全不透明度且没有圆点；单击一个即可在其专属应用程序作用域内启动。右键单击图标可执行“保留在快捷栏”/“从快捷栏移除”、“新建窗口”（当桌面文件可用时）以及“关闭”或“关闭所有窗口”。按 Escape 或在外部单击可关闭菜单。没有桌面文件的应用无法固定。

沿快捷栏拖动图标可重新排布固定项。将正在运行的应用拖入固定区域可将其保留在此，或将固定项拖出该区域以将其移除。其他图标会通过简短动画让出空间（在“减少动画效果”下为瞬时动画）；未固定的应用保留 Hyprland 的窗口顺序。仅当两个区域都包含应用时，细分隔线才将固定应用与其他运行应用分隔开。菜单和拖动操作使快捷栏保持显示。

固定项是桌面文件 ID，按顺序保存在 `$XDG_CONFIG_HOME`（通常为 `~/.config`）下机器本地的 `quickshell/desktop-bar/dock-pins.json` 中，以原子方式写入。全新安装没有固定项。窗口匹配使用桌面文件 ID、StartupWMClass 和应用程序类。

模糊强度与终端共享。在 Walker 或设置 (SUPER + ,) 中的“桌面栏”下选择“柔和”、“中等”（默认）或“强烈”。关于全局模糊限制和个人替代设置，请参阅[终端与编辑器](handbook:terminal)。

“设置 > 桌面栏”包含工作区标记（“圆点”、“字形”、“数字”和“符文”）。“窗口”页面保留窗口特效和间距。
