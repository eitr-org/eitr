# Eitr에 오신 것을 환영합니다

새로운 데스크톱이 준비되었습니다. 간단한 둘러보기를 진행하고, 필수 항목을 설정한 다음, 나만의 환경으로 맞춤 구성해 보세요.

<!-- eitr-welcome:tour -->
## 간단한 둘러보기

- **데스크톱 바**: 작업 공간, 시계 및 상태 아이콘이 화면 가장자리에 위치합니다. 제어 항목을 열려면 아이콘을 클릭하세요. 자동 잠금은 자동 잠금 기능을 직접 전환합니다.
- **런처**: 앱을 열려면 **SUPER + Space**를, 모든 메뉴를 보려면 **SUPER + F**를 누르세요. 입력을 시작하여 검색한 후 Enter를 누르세요.
- **설정**: 디스플레이, 사운드, 키보드, 모양 등을 설정하려면 **SUPER + ,**를 누르세요. 모든 페이지는 검색 가능합니다.
- **제어 센터**: 빠른 토글, 화면 캡처 및 어시스턴트와의 빠른 대화를 위해 **SUPER + I**를 누르세요.
- **테마**: 테마는 데스크톱 전체에 색상을 적용하고 고유한 배경화면을 제공합니다. 언제든지 전환하거나 나만의 테마를 직접 만들어 보세요.

## 필수 항목 설정

데스크톱에서 각 항목은 설정의 해당 페이지를 엽니다.

- **Wi-Fi**: 네트워크에 연결합니다.
- **테마 및 배경화면**: 매일 보고 싶은 색상과 아트를 선택하세요.
- **키보드**: 키보드 레이아웃을 추가, 정렬 및 전환하세요.
- **프로필 사진**: 계정에 표시될 사진을 선택하세요.
- **디스플레이**: 연결된 각 화면의 해상도와 배율을 설정하세요.
<!-- /eitr-welcome:setup -->

## 유용한 정보

**SUPER**는 Windows 또는 Command 로고 키입니다. **SUPER + Enter**를 누르면 터미널이 열립니다. 바 오른쪽의 아이콘은 숨겨져 있을 수 있습니다. 화살표를 클릭하여 표시하세요. 새로운 설치는 **Eitr** 테마와 **Eitr** 잠금 화면으로 시작하며, 기존 데스크톱은 이전 선택을 유지합니다.

이 환영 화면은 첫 로그인 시 자동으로 열립니다. 다시 보려면 **다음 로그인 시 이 환영 화면 표시**를 켜거나, **Learn > EITR Handbook** 또는 **SUPER + F1**에서 다시 열 수 있습니다.

**문제 발생 시 문제 보고 제안**은 기본적으로 켜져 있으며 충돌 알림 설정을 공유합니다. 프로그램 충돌 시 알림을 통해 도움말을 확인하거나 전송 전 검토할 수 있는 보고서를 제공합니다. [문제 해결](handbook:troubleshooting)을 참조하세요.

## 원하는 속도로 알아보기

검색을 통해 장 제목과 본문 내용을 찾을 수 있습니다. **Ctrl + F**로 검색에 포커스를 맞추고, Up/Down으로 일치 항목을 선택한 다음 Enter를 누르면 열립니다. **Page Up/Page Down**으로 스크롤하고, **Ctrl + Home/End**로 시작 또는 끝으로 이동하며, **Alt + Left/Right**로 이전 및 다음처럼 장 사이를 이동합니다. Escape, 닫기 버튼 또는 단축키를 누르면 창이 닫히며, 창 바깥쪽을 클릭해도 닫히지 않습니다.

핸드북은 명령을 직접 실행하지 않습니다. 코드 블록은 신중히 읽고 복사할 수 있는 예시이며, 외부 링크는 사용자가 클릭할 때만 열립니다. [단축키](handbook:shortcuts), [데스크톱 바](handbook:desktop-bar) 또는 [설정](handbook:system)에서 계속 알아보세요.

## Eitr에 포함된 기능

Eitr는 Arch Linux와 Hyprland를 기반으로 Walker의 검색 가능한 메뉴와 Quickshell 바를 중심으로 설계된 데스크톱 환경을 결합합니다. Full, Centered, Tabs, Islands, Dynamic 또는 Drop 레이아웃을 선택할 수 있으며, 패널을 통해 연결, 오디오, 디스플레이, 하드웨어, 알림, 날씨 및 작업 공간이 한곳에 통합됩니다. 테마는 데스크톱 전체를 조화롭게 꾸며주며, 나만의 테마를 직접 만들 수도 있습니다.

System Update는 공식 패키지, AUR 및 Flatpak 업데이트를 처리하며, 지원되는 배포판 설치 환경에서는 스냅샷을 생성합니다. 부트 가드는 로그인 전에 실패한 업데이트를 복구할 수 있습니다. 공장 초기화에는 지원되는 설치 환경과 첫 로그인 기준 상태, 경고 및 직접 입력하는 확인 과정이 필요합니다. 설치 프로그램은 오프라인 패키지 페이로드를 지원하며, 복구 및 설치는 문서화된 지원 레이아웃에 의존합니다.

Steam은 GameMode, MangoHud 및 gamescope와 함께 기본 설치되어 있으며, Install > Gaming에서 추가 항목을 제공합니다. HDR 제어는 지원되는 디스플레이에서 나타납니다. 게임 클라이언트나 HDR 모니터가 설치되어 있다고 해서 모든 게임의 동작이 보장되는 것은 아닙니다. Development 메뉴에서는 편집기, 런타임, Docker 및 AI 어시스턴트를 제공합니다. Git Accounts는 폴더별로 ID를 분리하며, 클라우드 메뉴는 공급자 컨텍스트를 명확하게 표시합니다. 사용 가능 여부는 설치 및 구성 상태에 따라 달라집니다.

캘린더와 미리 알림은 하루 일정을 계획하는 데 도움을 줍니다. 받아쓰기 기능은 설정 후 음성을 텍스트로 변환합니다. 원격 액세스 도구로는 Moonlight와 Sunshine이 포함되어 있으며, 필요한 도구를 직접 설치하고 구성할 수 있습니다. 플러그인은 전용 워크플로를 통해 Eitr의 기능을 확장합니다. 데스크톱 번역은 영어, 브라질 포르투갈어, 스페인어, 프랑스어, 독일어를 지원합니다. 오프라인 핸드북은 질문을 외부로 전송하지 않고 단축키, 설정, 초기 구성 및 복구 방법을 설명합니다. Control Center의 빠른 채팅은 선택한 어시스턴트를 사용하며, 대화 내용과 제한된 시스템 요약 정보 및 핸드북 컨텍스트를 함께 전송합니다. 명령을 실행하거나 설정을 변경할 수는 없습니다.
