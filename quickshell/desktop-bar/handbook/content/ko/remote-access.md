# 원격 접속

Sunshine 및 Moonlight를 사용하려면 설정 > 스트리밍을 열거나, Walker > 설정 > 장치 > 스트리밍에서 동일한 작업을 수행할 수 있습니다. 호스팅은 직접 활성화할 때까지 꺼져 있습니다. 현재 버전은 로그인되어 깨어 있는 Eitr 데스크톱을 제어합니다. 헤드리스 사용, 로그인 전 접속 및 Wake on LAN은 향후 별도로 작업될 예정입니다. 공유하는 동안 이 PC가 잠기면 원격 화면에도 잠금 화면이 표시됩니다. 연결된 사람은 누구나 이를 볼 수 있고 비밀번호를 입력할 수 있으므로, 프라이버시가 중요한 경우 자리를 비우기 전에 공유를 중지하세요.

설정 폴더에 구성 작업들이 그룹화되어 있습니다. 스트리밍 > 공유 설정에는 공유 설정, 공유 환경설정, 로그인 시 시작, 로그인 시 시작 끄기, 상세 상태 및 공유 설정 복원이 포함되어 있습니다. 일상적인 공유 작업(공유 시작, 공유 중지, 장치 페어링, 공유 상태 및 다른 PC에 연결)은 스트리밍 메뉴에 직접 위치합니다.

상세 상태를 선택하면 진단 터미널이 열리며 Esc를 누를 때까지 열린 상태로 유지됩니다.

## Eitr의 Sunshine

이 PC 공유 > 설정 > 공유 설정을 선택하세요. 설치에는 릴리스 관리자가 업스트림 소스로부터 빌드한 Eitr의 서명된 네이티브 Sunshine 패키지가 사용됩니다. 처음 클릭할 때 AUR 빌드는 수행되지 않습니다. Flatpak 및 AppImage는 KMS 캡처를 지원하지 않습니다. 기존 Sunshine 구성과 페어링된 장치는 유지됩니다. 다른 Sunshine 인스턴스를 동시에 실행하지 마세요.

전체 제어 권한에 대한 경고를 읽고, KMS 화면 캡처와 가상 키보드, 마우스 및 컨트롤러 입력을 허용하는 경우에만 `yes`를 입력하세요. 설정 과정에서 원래 권한이 `/var/lib/eitr/remote-access`에 비공개로 저장됩니다. uinput udev 규칙을 추가하고, 부팅 시 uinput을 로드하며, 데스크톱 사용자에게 장치 접근 권한을 부여하고 Sunshine에 `cap_sys_admin+p` 권한을 부여합니다. 이는 강력한 권한입니다.

공유 설정 복원은 공유를 중지하고, 저장된 파일과 장치 ACL을 복원하며, 캡처 권한을 제거합니다. 설정 시 uinput을 로드했다면 실행 취소 과정에서 언로드도 수행합니다. 다른 애플리케이션에서 여전히 uinput을 사용 중인 경우, 실행 취소는 실패를 보고하고 저널을 유지하므로 해당 애플리케이션을 닫은 후 다시 시도할 수 있습니다.

공유 시작은 원격 장치에 제어 권한을 부여하기 전에 확인을 요청합니다. 로컬 웹 설정이 `https://localhost:47990`에서 열립니다. 처음 사용할 때는 비밀번호를 설정하는 동안 스트리밍이 차단된 상태로 유지됩니다. 터미널로 돌아와 비밀번호가 설정되었음을 확인하면 관리자 비밀번호로 원격 제어가 활성화됩니다. 로컬 자체 서명 인증서는 해당 주소에서만 수락하세요.

페어링하기 전에 Sunshine의 사용자 이름과 강력한 비밀번호를 설정하세요. 설정의 공유 환경설정에서 이 화면으로 다시 돌아올 수 있으며, 장치 페어링은 PIN 페이지를 엽니다. 본인의 Moonlight 장치에 표시된 PIN만 입력하세요. 라우터 자동 구성은 꺼진 상태로 유지하세요. Eitr는 `upnp=off`를 강제합니다. 라우터 포트 포워딩을 구성하지 마세요.

TCP 47984, 47989, 48010 및 UDP 47998-48000은 직접 연결된 사설 LAN 서브넷에서만 허용됩니다. TCP 47990은 다른 방화벽 규칙에서 허용하더라도 이 PC로만 제한됩니다. LAN 범위는 시작할 때마다 캡처되므로 네트워크를 변경한 후에는 공유를 중지했다가 다시 시작하세요. 신뢰할 수 있는 홈 네트워크만 사용하세요.

공유 중지는 로그인 시 시작도 비활성화하고 기존 스트림을 포함한 스트리밍 포트를 닫습니다. 서비스 실패 시에도 포트가 닫히며, 런타임에 열린 포트는 재부팅 후 유지되지 않습니다. 처음 시작한 이후에는 질문이나 비밀번호 없이 공유 시작과 공유 중지가 즉시 전환됩니다. 로그인 시 시작은 선택 사항이며 스트리밍 패널이나 메뉴에서 즉시 전환할 수 있습니다. 로그인 시 시작 끄기는 수동 공유 상태를 유지합니다.

공유 상태에는 서비스 오류가 표시됩니다.

Sunshine 패키지가 업데이트되면 실행 파일이 교체되어 캡처 기능 권한이 지워집니다. 이후 업데이트가 공유를 설정한 계정에 권한을 다시 부여합니다. 공유가 여전히 시작되지 않는 경우 스트리밍 토글에 이유가 표시됩니다. 공유 설정을 다시 실행하거나, 처음 설정한 후 로그아웃했다가 다시 로그인하세요. 원래의 실행 취소 기록은 유지됩니다.

Sunshine은 root 또는 공유 계정으로서만 KMS 기능을 실행합니다. 설정 시 실행 파일이 `root:eitr-sharing` 모드 `0750`으로 설정되고 사용자의 계정이 해당 시스템 그룹에 추가됩니다. 사용자 서비스가 새 그룹을 적용받을 수 있도록 공유를 시작하기 전에 로그아웃했다가 다시 로그인하세요. 설정은 실행 중인 모든 공유 프로세스를 활성 상태로 유지하지만, 다음 로그인 전에 다시 시작하면 실패할 수 있습니다.

공유 중지는 설정된 권한을 유지합니다. 공유 설정 복원은 그룹 멤버십과 모든 바이너리 기능 권한을 제거하고 실행 파일을 이전 설정 기록 복원을 포함하여 `root:root` 모드 `0755`로 되돌립니다. 패키지 업데이트 후 공유 설정은 기능 권한을 다시 부여하기 전에 소유권과 모드를 복구합니다.

## Mac의 Moonlight

[Moonlight 프로젝트](https://moonlight-stream.org/)에서 Moonlight를 설치하세요. 첫 테스트에서는 Eitr와 Mac을 동일한 홈 네트워크에 두세요. 검색을 통해 찾지 못하면 Eitr의 LAN 주소를 직접 수동으로 추가하세요. PC를 선택하고 PIN을 확인한 다음, Eitr에서 장치 페어링을 사용하세요. 애플리케이션과 게임을 제어하려면 데스크톱을 선택하세요. Sunshine 설정에서 캡처할 디스플레이를 선택하고, 각 모니터를 개별적으로 확인하세요. 게임 > Moonlight 및 다른 PC에 연결에서 반대 방향으로 연결하기 위한 Eitr 클라이언트를 설치하거나 열 수 있습니다. 새로 설치한 시스템에는 이러한 앱이 포함되어 있으며, 명시적으로 활성화할 때까지 공유는 꺼진 상태로 유지됩니다.

Mac에서의 SUPER 단축키: Moonlight 설정에서 **Capture system keyboard shortcuts**(전체 화면 또는 항상)를 켜세요. 이렇게 설정해야만 Moonlight가 Mac의 Command 키를 SUPER로 전송합니다. 그렇지 않으면 Command 단축키가 Mac에 머무르게 됩니다. 세션 중에 Ctrl+Alt+Shift+K를 누르면 캡처를 켜거나 끌 수 있습니다.

## 테스트된 항목

자동화 테스트는 모의 객체(mock)를 사용합니다. Moonlight를 실행하는 MacBook과 실제 데스크톱(모니터 1대 및 2대) 환경에서 다음 항목이 테스트되었습니다. 홈 네트워크 및 VPN을 통한 외부 접속 환경에서 설정, 공유 시작, 주소로 페어링, 비디오, 키보드, 마우스, 오디오, 잠금 화면(Mac에서 잠금 해제), 로그인 시 시작, 공유 중지 및 공유 설정 복원이 테스트되었습니다. 컨트롤러, 기타 GPU 및 다른 클라이언트는 아직 테스트되지 않았습니다.

스트리밍은 장치 메뉴 아래 연결 옆에 위치합니다. Sunshine은 공유 상태, 설정, 시작/중지, 로그인 시 시작, 페어링, 설정, 진단 및 설정 복원을 표시합니다. Moonlight는 설치 상태와 설치/열기 버튼을 표시합니다.
