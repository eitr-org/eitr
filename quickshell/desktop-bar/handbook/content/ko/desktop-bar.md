# 데스크톱 바 및 작업 공간

<!-- eitr-figure: bar-anatomy -->

Full 바. Eitr 로고는 제어 센터를 엽니다; 그 뒤로 작업 공간 개요(Overview), 작업 공간 마커, AI 사용량, 하드웨어 및 자동 잠금이 이어집니다. 날짜와 시간은 중앙에 위치하며, 그 앞에는 미디어가, 뒤에는 날씨가 표시됩니다. **아이콘 표시**는 오른쪽의 상태 아이콘을 표시하거나 숨깁니다; 알림이 마지막에 위치합니다.

플러그인 항목은 자동 잠금 뒤, 시계 앞, 시계 뒤 또는 상태 그룹에 배치할 수 있습니다. 설정 > 플러그인 > 해당 플러그인 > 표시줄에서 위치를 선택합니다. 배치 순서에 따라 자동 잠금 뒤에는 4개, 시계 양쪽에는 각각 2개, 상태 그룹에는 8개까지 표시됩니다. 초과 항목은 선택한 위치에서 숨겨집니다. Centered와 Dynamic은 확장 시 표시하고, Tabs와 Islands는 포함하며, Drop은 표시줄의 플러그인 항목을 숨깁니다. 시계는 화면 중앙을 유지합니다. World clock은 선택 가능한 공식 플러그인이며 표시줄의 12/24시간 설정을 따릅니다.

Weather는 공식 내장 플러그인으로 기본적으로 시계 뒤에 설치됩니다. Eitr Store > 설치됨 > 플러그인에서 제거하면 Drop 홈을 포함한 모든 곳에서 날씨가 숨겨집니다. 업데이트 후에도 다시 추가되지 않습니다. 발견에서 패키지에 포함된 사본으로 다운로드 없이 다시 설치할 수 있습니다. 도시 검색 선택은 현재 세션에서만 유지됩니다。

설정 > 창에서 창 레이아웃과 모니터는 두 버튼 선택 방식을 사용합니다. 작업 공간 수와 항상 표시는 드롭다운 목록을 사용합니다; 항상 표시는 2부터 현재 작업 공간 수까지 제공합니다. 각 설정 아래의 설명은 선택된 창 레이아웃과 스크롤 옵션을 포함하여 해당 설정의 효과를 설명합니다.

## 업데이트

알림 앞에 있는 업데이트 아이콘은 로그인 직후 및 6시간마다 확인을 수행합니다. 클릭하면 시스템 업데이트를 실행합니다; 오른쪽 클릭하면 다시 확인합니다. 시스템 업데이트가 성공하면 다음 확인 전까지 최신 상태로 표시되며, 즉시 다른 확인을 시작하지 않습니다. 오프라인이거나 실패한 확인은 사용 불가 상태를 표시하며, 거짓으로 “최신 상태”를 표시하지 않습니다. 이 확인은 비공개 패키지 데이터베이스를 사용하며 패키지를 업그레이드하지 않습니다.

## 바 레이아웃 변경

- **빈 바 공간**을 더블 왼쪽 클릭하여 테마 색상 → 블러 → 웹사이트 순으로 전환할 수 있습니다(새 설치본은 테마 색상으로 시작). 웹사이트는 테마에 따라 라이트 또는 다크 모드로 Eitr 웹사이트의 색상을 사용합니다.
- 빈 공간을 더블 오른쪽 클릭하여 Full → Centered → Tabs → Islands → Dynamic → Drop → Full 순으로 전환할 수 있습니다.
- 빈 공간을 위, 아래, 왼쪽 또는 오른쪽으로 드래그하여 바를 이동하세요. 좌우 바는 상하 바만큼 얇습니다: 시계는 캘린더 아이콘과 함께 분 위에 시간을 표시하고, 날씨는 해당 아이콘을 표시합니다; 마우스를 올리면 날짜와 온도가 표시됩니다.
- 설정 > 데스크톱 바의 **시계**는 모든 바 가장자리에서 AM/PM이 포함된 12시간제(기본값) 또는 24시간제 시간을 표시합니다.
- 동일한 설정이 **설정 > 데스크톱 바**의 레이아웃, 모양 및 동작 탭에 있습니다.
- **디스플레이**(표시 위치)는 바를 기본값인 기본 디스플레이에만 배치하거나 모든 디스플레이에 배치합니다. 모든 디스플레이에 바가 있는 경우 각 바는 해당 화면에 표시된 작업 공간을 표시하고, SUPER + I와 같은 단축키는 현재 사용 중인 디스플레이에서 열리며, 알림은 기본 디스플레이에만 팝업으로 나타납니다. 디스플레이 패널에서 기본 디스플레이를 선택하세요.

<!-- eitr-figure: bar-layouts -->

더블 오른쪽 클릭으로 전환되는 순서대로 나타난 6가지 레이아웃. 평상시 Centered는 시계만 표시하고, Dynamic은 세 개의 작은 아일랜드를 표시하며, Drop은 단일 시간 알약 모양을 표시합니다; Centered와 Dynamic은 마우스를 올리면 펼쳐집니다.

설정 > 데스크톱 바에서 레이아웃을 선택하세요. 6가지 모두 모든 화면 가장자리에서 작동합니다.

| 레이아웃 | 표시 및 동작 |
| :--- | :--- |
| Full | Full은 가장자리에 전체 바를 유지합니다. 패널이 바와 연결됩니다. |
| Centered | Centered는 마우스를 올릴 때까지 시계만 표시합니다. 핀을 사용하거나 설정 > 데스크톱 바(Walker에서도 가능)의 확장 상태 유지를 사용하여 확장 상태를 유지할 수 있습니다; 패널은 바 옆에 플로팅 상태로 표시됩니다. |
| Tabs | Tabs는 얇은 띠로 연결된 3개의 탭을 사용합니다. 상태 아이콘과 날씨가 계속 표시됩니다. |
| Islands | Islands는 각 그룹에 고유한 알약 모양을 부여하며, 모든 상태 아이콘이 항상 표시됩니다. 패널을 열면 해당 알약 모양이 확장되고 인접한 그룹들이 옆으로 이동합니다. |
| Dynamic | Dynamic은 로고, 시계 및 네트워크/배터리의 세 아일랜드로 시작하며, 무언가 재생 중일 때는 로고와 시계 사이에 미디어 아일랜드가 추가됩니다. 하나에 마우스를 올리면 확장되고; 패널을 열면 해당 아일랜드가 패널로 커집니다. |
| Drop | Drop은 가장자리 중앙의 한 알약 모양에 시간만 표시합니다. 클릭하면 대시보드로 확장되며; 오른쪽 클릭하면 빠른 제어로 바로 이동합니다. 자동 숨김을 사용하면 가장자리에서 물방울이 떨어져 알약 모양으로 부풀어 오를 때까지 화면에 아무것도 남지 않습니다. |

**아일랜드 스타일**(설정 > 데스크톱 바 > 레이아웃, 또는 Walker > 설정 > 데스크톱 > 데스크톱 바 > 아일랜드 스타일)은 Islands, Dynamic, Drop이 화면 가장자리와 만나는 방식을 고릅니다. 떠 있음은 알약 모양을 바깥 여백의 절반만큼 가장자리에서 띄우고, 붙임은 가장자리에 붙여 가장자리 쪽은 각지게, 옆면은 곧게 만들며 패널도 가장자리에서 펼쳐집니다. **옆면 스타일**은 Tabs와 Centered가 가장자리와 만나는 방식을 고릅니다. 45° 경사 또는 곧은 옆면이며, 곧은 옆면의 Tabs는 탭 사이의 얇은 띠도 없앱니다.

## Drop의 대시보드

Drop의 시간 알약 모양을 클릭하면 알약 모양 자체가 대시보드로 커집니다. 페이지를 옆으로 드래그하거나(오른쪽은 앞으로, 왼쪽은 뒤로 가며 둘 다 순환됨), 화살표 키 또는 가로 스크롤을 사용하세요. Esc를 누르거나 바깥쪽을 클릭하면 닫힙니다. 대시보드의 어떤 항목도 다른 패널을 열지 않습니다: 세부 정보는 뒤로 가기 화살표와 함께 그 자리에서 열립니다.

| 페이지 | 구성 내용 |
| :--- | :--- |
| 캘린더 및 날씨 | 월 옆에 날씨가 표시됩니다. 날씨를 클릭하면 전체 예보와 도시 검색이 열리고; 특정 날짜를 클릭하면 해당 날의 일정 확인 및 특정 시간 알림 추가가 가능합니다. |
| 미디어 | 음악에 맞춰 움직이는 바로 둘러싸인 커버, 곡, 가사, 컨트롤 및 진행률 표시줄. 무언가 재생 중일 때 표시됩니다. |
| OBS | 일시정지, 중지, 방송 시작, 챕터 마크, 녹화 폴더 및 OBS 자체를 포함한 녹화 및 스트리밍 상태. OBS가 열려 있는 동안 표시됩니다. |
| 빠른 제어 | WiFi, Bluetooth, 사운드 및 마이크는 해당 네트워크와 장치를 그 자리에서 엽니다; 비행기 탑승 모드, 무음, 야간 모드, 자동 잠금, 녹화 및 설정; 볼륨, 마이크 및 (노트북의 경우) 밝기. |
| 타이머 및 집중 | 카운트다운, 스톱워치 또는 5분 휴식이 포함된 25분 집중 세션. 대시보드가 닫혀 있어도 계속 실행되며 종료 시 알림을 보냅니다. |
| 성능, AI 사용량 및 알림 | CPU, GPU, RAM 및 스토리지; 각 어시스턴트의 한도(하나를 클릭하면 전체 표시); 알림 목록. |

모든 레이아웃에서 시계는 녹화 점이 위치하는 옆자리에 현재 일어나는 일을 표시합니다: 이벤트가 10분 이내에 시작될 때의 캘린더 마크(클릭하면 해당 날의 일정 표시), 타이머 또는 집중 세션이 실행 중일 때의 링(클릭하면 제어 센터 > 도구 > 타이머 및 집중 열기). 새 알림이 오면 바의 종이 두 번 울립니다; 종이 숨겨진 위치(축소된 상태의 Centered, 평상시의 Dynamic)에서는 대신 시계 옆으로 종이 슬라이드되어 나타납니다. 노트북 배터리는 15% 및 5%에서 시간을 빨간색 백분율로 잠시 대체하며; 작업 공간이 숨겨진 곳에서는 전환한 작업 공간 번호도 이와 같이 시간을 잠시 대체합니다.

시간 주변에서 Drop의 알약 모양은 필요한 공간만 확보하면서 일어나는 일을 표시합니다. 시간 앞쪽: 녹화 중일 때 빨간 점, 이벤트가 10분 이내에 시작될 때 캘린더 마크, 타이머 실행 중일 때 링, 바가 업데이트를 확인할 때 회전하는 화살표, 업데이트 알림이 떠 있을 때 업데이트 마크(클릭하면 시스템 업데이트 열기), 음악이 재생 중일 때 음표(클릭하면 미디어 열기). 시간 뒤쪽: 새 알림이 올 때 두 번 울리는 종(클릭하면 목록 열기). 작업 공간을 전환하면 시간이 해당 번호로 잠시 대체되며; 노트북 배터리도 15% 및 5%에서 빨간색으로 동일하게 대체됩니다. 음표를 오른쪽으로 드래그하면 알약 모양이 한 줄의 가사로 바뀝니다; 어느 쪽으로든 드래그하거나 일시정지 또는 중지하면 원래대로 돌아옵니다.

**온라인 가사**(설정 > 데스크톱 바 > 동작, 또는 Walker > 설정 > 데스크톱 > 데스크톱 바 > 온라인 가사)는 기본적으로 꺼져 있습니다. 켜져 있으면 Drop이 LRCLIB(lrclib.net)에서 재생 중인 곡을 검색하여 제목, 아티스트, 앨범 및 길이를 전송합니다. 플레이어가 자체적으로 보낸 가사가 항상 먼저 사용됩니다.

## 작업 공간

설정 > 창 > 작업 공간(또는 Walker > 설정 > 데스크톱 > 창 > 작업 공간)에서는 **모니터**, **작업 공간 수**(5–10, 기본값 10) 및 **항상 표시**(2부터 총 개수까지, 기본값 5)를 선택합니다. 기본값인 **번호 공유**는 모든 모니터에 고유한 1…N을 부여합니다: SUPER+k는 모든 모니터를 함께 전환하고, SUPER+Shift+k는 창을 현재 모니터에서 이동하며 모든 모니터가 해당 번호로 함께 전환됩니다. **모니터 간 분할**은 N을 균등하게 분할하며, 기본 디스플레이에 먼저 할당하고 남은 공간도 거기에 먼저 배정합니다; 다른 디스플레이는 왼쪽에서 오른쪽으로, 그다음 이름 순으로 따릅니다. SUPER+k는 소유 디스플레이로 포커스를 맞춥니다. N보다 큰 키는 아무 동작도 하지 않습니다. 마커 하한선은 각 모니터의 범위에 상대적이며; 더 높은 마커는 현재 또는 가장 높은 사용 중인 작업 공간까지 표시된 후 더 이상 필요하지 않으면 사라집니다. 디스플레이를 연결하거나 제거하고 기본 디스플레이를 변경하면 창을 잃지 않고 할당이 다시 계산됩니다; 창은 현재 디스플레이에서 가장 가까운 유효한 번호로 이동합니다. 단일 모니터는 두 모드에서 동일한 동작을 유지합니다.
마커를 오른쪽 클릭하여 점, 글리프, 숫자 또는 룬을 실시간 예시와 함께 선택하세요.
네 가지 선택 항목 모두 스크롤 없이 모든 바 가장자리의 팝업에 들어맞습니다.
룬이 기본값입니다. 활성 마커는 채워진 배경 없이 강조 색상의 글리프를 사용합니다.
룬은 작업 공간 1부터 10까지를 엘더 푸타르크(Elder Futhark)의 첫 10개 룬 문자(ᚠ ᚢ ᚦ ᚨ ᚱ
ᚲ ᚷ ᚹ ᚺ ᚾ)로 표시합니다.

**SUPER + 1–9/0**은 작업 공간을 전환합니다; **SUPER + Shift + 1–9/0**은 창을 이동합니다.
**SUPER + Tab**은 작업 공간 개요(Overview)를 엽니다. 미리보기를 클릭하거나 화살표와 Enter를 사용하세요;
1–9/0은 직접 전환합니다. 번호가 매겨진 사용 중인 작업 공간만 나타나며,
미리보기는 메모리에 유지됩니다. Escape 또는 바깥쪽 클릭 시 개요가 닫힙니다.

**SUPER + S**는 개요(Overview)와 별개인 특수 작업 공간을 토글합니다.
**SUPER + Shift + Space**는 바의 자동 숨김을 켜거나 끕니다; 바가 제어 센터에서 숨겨져 있던 경우 먼저 바를 다시 가져옵니다. 알림은 어느 쪽이든 계속 작동합니다.

빈 데스크톱 공간에서 배경화면/테마 마우스 제스처는
**둘러보기 > 마우스 제스처**에 나열되어 있습니다. 확실하지 않을 때는 키보드 캐러셀 단축키를 사용하세요.

오디오/마이크 컨트롤은 별도의 출력 및 마이크 섹션이 있는 하나의 패널을 엽니다. 스트리밍은 OBS 바로 앞에 위치합니다. 헤더의 스위치가 공유를 시작하고 세부 정보가 이어지며, 설정 또는 진단 동작은 "…" 메뉴에 있습니다. 아이콘 버튼은 마우스를 올릴 때 배경이 표시됩니다; 패널은 열릴 때 스스로 새로고침되고, 새로고침 아이콘은 로드되는 동안에만 회전하며, 툴팁은 포인터 근처에 나타납니다. 스위치와 인셋 동작 버튼은 컴팩트한 공유 크기를 사용합니다.

**음악 시각화**는 테마 색상으로 cava를 엽니다. 미디어 이퀄라이저를 오른쪽 클릭하면 동일한 시각화 도구가 열립니다; 왼쪽 클릭은 기존대로 미디어 세부 정보를 엽니다. 닫으려면 **q** 또는 **Esc**를 누르세요. 기존 데스크톱에 cava 패키지가 없는 경우 먼저 설치됩니다.

**자동 숨김**(설정 > 데스크톱 바)은 포인터가 벗어난 후 짧은 지연 시간이 지나면 바를 슬라이드하여 치웁니다. 화면 가장자리에 닿으면 다시 나타납니다. Full, Centered, Tabs, Islands, Dynamic 및 Drop 레이아웃의 네 가지 가장자리 모두에서 작동합니다; Drop의 경우 바 색상의 물방울이 가장자리에서 떨어져 시간 알약 모양으로 부풀어 오릅니다. 새 알림이 오면 팝업이 닫힐 때까지 바가 표시됩니다. 패널과 팝업이 열려 있거나 바를 드래그하는 동안에는 계속 표시되며; 그 후에 다시 숨겨집니다. 자동 숨김이 켜져 있는 동안 바는 창 공간을 예약하지 않습니다: 창을 이동하는 대신 창 위로 슬라이드합니다. 이 설정은 중앙 정렬 레이아웃 핀과 별도로 저장되며 새 설치본에서는 기본적으로 꺼져 있습니다.

**움직임 줄이기**(설정 > 데스크톱 바)는 패널 펼치기/접기, 개요 진입, 알림 전환 및 장식용 바 애니메이션을 즉각적으로 만듭니다. 기본적으로 꺼져 있으며 `bar-settings.json`에 저장됩니다. 데이터를 새로고침하거나 알림을 닫거나 자동 숨김을 지연시키는 타이머는 정상적인 동작을 유지합니다.

미디어 스타일은 `bar-settings.json`에 저장됩니다: 설정 > 데스크톱 바에서 바(기본값, 10개 바) 또는 라인(단순하고 매끄러운 오디오 파형)을 선택하세요. 표시기는 재생 컨트롤 앞에 위치하며 모든 레이아웃에서 고정된 크기를 유지하고 좌우 가장자리에서는 회전합니다. 마우스를 올리면 곡명이 표시됩니다; 왼쪽 클릭은 미디어 세부 정보를 열고 오른쪽 클릭은 음악 시각화를 엽니다. 왼쪽으로 드래그하면 그 자리에 한 줄의 가사가 표시됩니다; 그 줄을 어느 방향으로든 드래그하면 원래대로 돌아옵니다. 재생이 일시정지되면 라인이 평평해집니다. 움직임 줄이기는 감속 효과 없이 실시간 오디오 레벨을 유지하며 장식용 대체 움직임을 중지합니다.

## 가장자리 독

바 반대편 화면 가장자리에 닿으면 애플리케이션 독이 나타납니다. 그 가장자리에서 곧은 면이 가장자리에 닿으며 펼쳐지고, 창을 이동하거나 크기를 조정하지 않고 창 위에 표시되며, 포인터가 벗어난 후 350 ms 뒤에 공유된 320 ms 동작으로 숨겨집니다(움직임 줄이기 시 즉시 숨김). 기본 화면에 나타나거나 디스플레이가 모두로 설정된 경우 모든 화면에 나타나며, 전체 화면 창 위에는 절대 나타나지 않습니다.

독은 고정된 앱을 먼저 표시하고, 그 뒤에 Hyprland의 창 순서대로 열려 있는 다른 애플리케이션을 표시합니다. 각 36 px 아이콘 슬롯은 6 px 간격을 가지며 애플리케이션의 데스크톱 아이콘을 사용하고 글리프 대체 수단을 가집니다; Eitr 자체 작업 및 메뉴 터미널은 하나의 Eitr 로고 아이콘을 공유합니다. 아이콘 아래의 점은 창 수를 최대 3개까지 표시하며, 해당 화면의 현재 작업 공간에 창이 없는 경우 흐려집니다.

마우스를 올리면 이름과 창 수가 표시됩니다; 포인터 근처의 아이콘이 커지며(가장 가까운 것이 가장 많이 커짐), **움직임 줄이기**가 켜져 있지 않는 한 독이 길어져 아이콘을 내부에 유지합니다. 가장 최근에 사용한 창으로 포커스를 맞추려면 클릭하세요(작업 공간 전환 포함); 다시 클릭하면 다음 창으로 이동합니다. 마우스 가운데 클릭은 가장 최근 창을 닫습니다.

긴 목록은 독을 따라 스크롤됩니다. 표면은 블러/테마 색상 및 모서리 환경설정을 따릅니다.

**독**은 **설정 > 데스크톱 바**에서 끄거나 켤 수 있습니다. `bar-settings.json`의 `dock` 설정 기본값은 `"yes"`입니다. 독 단축키는 없습니다.

고정된 앱은 닫혀 있을 때 점 없이 완전한 불투명도로 유지됩니다; 클릭하면 자체 애플리케이션 스코프에서 실행됩니다. 아이콘을 오른쪽 클릭하면 독에 보관 / 독에서 제거, 새 창(데스크톱 엔트리를 사용할 수 있는 경우), 닫기 또는 모든 창 닫기 메뉴가 나타납니다. Escape를 누르거나 바깥쪽을 클릭하면 메뉴가 닫힙니다. 데스크톱 엔트리가 없는 앱은 고정할 수 없습니다.

독을 따라 아이콘을 드래그하여 고정 항목의 순서를 변경하세요. 실행 중인 앱을 고정 영역으로 드래그하여 유지하거나, 고정 항목을 해당 영역 밖으로 드래그하여 제거하세요. 다른 아이콘은 짧은 애니메이션과 함께 자리를 비켜줍니다(움직임 줄이기 시 즉각 변경); 고정되지 않은 앱은 Hyprland의 창 순서를 유지합니다. 두 섹션 모두에 앱이 포함된 경우에만 얇은 구분선이 고정 앱과 실행 중인 다른 앱을 구분합니다. 메뉴가 열려 있거나 드래그 중인 동안에는 독이 계속 표시됩니다.

고정 항목은 `$XDG_CONFIG_HOME`(보통 `~/.config`) 아래의 로컬 머신 `quickshell/desktop-bar/dock-pins.json`에 순서대로 원자적으로 기록되는 데스크톱 엔트리 ID입니다. 새 설치본에는 고정 항목이 없습니다. 창 일치 확인에는 데스크톱 엔트리 ID, StartupWMClass 및 애플리케이션 클래스가 사용됩니다.

블러 강도는 터미널과 공유됩니다. Walker의 데스크톱 바 또는 설정(SUPER + ,)에서 부드럽게, 중간(기본값) 또는 강하게를 선택하세요. 전역 블러 제한 및 개인 재정의에 대해서는 [터미널 및 편집기](handbook:terminal)를 참조하세요.

설정 > 데스크톱 바에는 작업 공간 마커(점, 글리프, 숫자 및 룬)가 포함되어 있습니다. 창 페이지는 창 효과와 간격을 유지합니다.
