# 언어

Eitr는 시스템의 메시지 로캘을 따릅니다. **Walker > 설정 > 장치 > 언어**는 사용 가능한 언어 목록을 표시하며 현재 선택된 언어에 체크 표시가 됩니다. 언어 또는 **시스템 기본값**을 선택한 다음 로그아웃했다가 다시 로그인하세요. Eitr는 자동으로 로그아웃하지 않습니다.

Eitr는 **LC_ALL**, **LC_MESSAGES**, **LANG** 순으로 확인합니다. 비어 있는 변수는 무시됩니다. `LC_MESSAGES`는 날짜, 숫자 또는 통화 형식을 변경하지 않고 메시지만 변경합니다. `LC_ALL`은 모든 로캘 범주를 재정의하므로 일반적으로 설정하지 않은 상태로 둡니다. `C`, `POSIX` 및 지원되지 않는 언어는 영어를 사용합니다. 번역되지 않은 메시지는 영어로 대체되며, 누락된 핸드북 장은 장 전체가 영어로 대체됩니다.

## 시스템 언어 변경

언어 선택기는 `~/.config/environment.d/90-eitr-language.conf`에만 기록합니다. 다음 사용자 세션을 위해 날짜 및 숫자 형식을 유지하면서 `LC_MESSAGES`를 설정하고 `LC_ALL`을 비웁니다. **시스템 기본값**은 해당 환경설정을 제거합니다. `/etc/locale.conf`를 수정하거나 로캘을 직접 생성하지는 않습니다. 필요한 경우 시스템 로캘 구성을 사용하세요. Arch Linux에서는 `/etc/locale.gen`에서 원하는 로캘을 활성화하고 `sudo locale-gen`으로 설치된 로캘을 다시 생성합니다. 그런 다음 `/etc/locale.conf`에서 언어를 설정하세요. 예:

```text
LANG=pt_BR.UTF-8
```

Eitr는 `pt_BR.UTF-8`(브라질 포르투갈어), `es_ES.UTF-8`(스페인어), `de_DE.UTF-8`(독일어), `fr_FR.UTF-8`(프랑스어), `ja_JP.UTF-8`(일본어), `zh_CN.UTF-8`(중국어 간체), `ko_KR.UTF-8`(한국어)로 번역되어 있습니다. 설치 프로그램의 첫 단계에서 새 시스템의 언어를 고릅니다. 번역은 AI로 만들어져 작은 오류가 있을 수 있으며, 수정 제안은 언제나 환영합니다(아래 참조). 지역별 변형은 기본 언어로 대체될 수 있습니다. 터미널에서 `locale`을 실행하여 재정의된 항목을 확인하고, `locale -a`로 설치된 로캘을 확인하세요. 로그아웃 후 다시 로그인하면 데스크톱, 메뉴 및 새로 열리는 터미널에 언어가 적용됩니다. 선택기는 다음 세션을 변경하므로 이미 실행 중인 응용 프로그램은 기존 언어를 유지합니다.

## 번역 기여하기

영어 텍스트가 원본입니다. 카탈로그는 `i18n/catalogs/<locale>/`에 위치하며, 영어 키를 유지한 채 번역된 값을 수정합니다. Python 및 셸 메시지는 단일 `eitr` gettext 도메인을 사용합니다. `%1` 및 `{name}`과 같은 자리표시자, 글리프, 패키지 이름, 명령 및 파일 경로는 변경하지 않고 그대로 유지하세요. 파괴적인 작업을 확인하기 위해 입력하는 단어는 확인 검사에서 허용하는 단어와 정확히 일치해야 합니다.

핸드북 장은 `quickshell/desktop-bar/handbook/content/<locale>/<chapter-id>.md`에 들어갑니다. `handbook:` 링크, 코드 블록 및 명령은 변경하지 않고 유지하세요. 키보드 및 마우스 표는 표준 단축키 소스로부터 생성되므로 바인딩 목록을 따로 관리하지 말고 핸드북 카탈로그에서 해당 메시지를 번역하세요.

`python3 tools/i18n-build.py --check`를 실행하고, `python3 tools/handbook-build.py`로 핸드북을 다시 빌드한 다음, 해당 빌드의 `--check` 및 `bash tools/check.sh`를 실행하세요. 카탈로그 검사는 누락된 메시지와 변경된 자리표시자를 표시합니다. 제출하기 전에 화면 밖 미리보기에서 긴 번역을 확인하세요.

변경된 장의 번역을 완전히 마친 후에는 `source-hashes.json`의 해당 항목을 영어 원본의 SHA-256 해시로 업데이트하세요. 빌드 검사는 변경되었거나 기록되지 않은 영어 원본을 표시합니다. 카탈로그를 다시 빌드하는 것만으로는 원본 변경 사항이 반영되지 않습니다.

시스템 기본값 행에는 `/etc/locale.conf`에서 확인된 기본 이름(`LC_ALL`, `LC_MESSAGES`, `LANG` 순, 빈 값은 무시)이 표시됩니다. 세션 재정의는 무시됩니다. English는 영어를 강제 적용하고, 시스템 기본값은 시스템 설정을 따릅니다. 시스템 로캘을 읽을 수 없는 경우 해당 행은 기본 레이블을 유지합니다.

시스템 기본값과 일치하는 고정 언어는 저장된 명시적 선택 항목이 아닌 한 숨겨져 현재 선택 항목이 계속 표시됩니다. 시스템 기본값을 확인할 수 없는 경우 모든 언어가 계속 목록에 표시됩니다.
