# 보안 및 잠금

**SUPER + M**을 누르면 즉시 화면이 잠깁니다. 바 왼쪽(AI 사용량 뒤)에 있는 자동 잠금 아이콘을 클릭하여 유휴 시 자동 잠금을 켜거나 끌 수 있으며, 툴팁에 현재 상태가 표시됩니다. 활성화되면 15분 동안 유휴 상태일 때 화면이 잠기고, 30분 후 화면이 꺼지며, 60분 후 컴퓨터가 절전 모드로 들어갑니다. 제어 센터에도 동일한 자동 잠금 토글과 잠금 버튼이 있습니다.

잠금 20초 전, 지원되는 디스플레이는 이전 밝기의 약 30%로 어두워집니다(절대 0%가 되지 않음). 활동이 감지되면 잠긴 후에도 정확히 이전 밝기로 복원되며, 자동 잠금을 꺼도 밝기가 복원됩니다. DDC 밝기 제어를 지원하지 않는 외장 모니터는 제외됩니다.

## 비밀번호 및 대체 인증

**설정 > 사용자 > 비밀번호 변경**에서 계정 비밀번호를 변경할 수 있으며, 로그인 키링도 새 비밀번호와 함께 열리도록 유지됩니다. 지문 및 FIDO2 보안 키는 별도의 등록/활성화 워크플로가 있습니다. FIDO2 보안 키는 노트북 지문 인식기가 아닌 물리적 보안 장치입니다. 먼저 등록한 다음 인증을 활성화하세요. 도우미가 PAM 설정을 백업하지만, 작동하는 비밀번호와 TTY에 접근할 수 있는 방법을 반드시 유지하세요.

비밀번호 인증으로 돌아가기를 선택하면 비밀번호 전용 동작으로 복원됩니다. 이러한 변경 사항은 지원되는 잠금 화면/로그인/sudo PAM 서비스에 영향을 미치며, 하드웨어 지원 및 설치된 도우미가 필요합니다. 지문 인증을 사용하면 비밀번호 프롬프트 표시가 잠시 지연될 수 있습니다. 이 페이지를 읽는 것만으로는 PAM이 수정되지 않습니다.

## 관리자 비밀번호 프롬프트

앱이나 Eitr 자체에 관리자 권한이 필요할 때(소프트웨어 설치, 시스템 설정 변경 등), 바의 테마로 그려진 비밀번호 프롬프트가 현재 사용 중인 화면을 덮습니다. 요청한 대상, 인증할 계정(여러 계정이 가능한 경우 선택 가능), polkit 동작이 포함된 요청 세부 정보가 표시됩니다. Enter를 누르면 인증되고, Escape 또는 취소를 누르면 거부되며, 프롬프트 바깥을 클릭해도 아무 반응이 없습니다. 잘못된 비밀번호를 입력하면 오류가 표시되고 다시 시도할 수 있습니다. 여러 요청이 있는 경우 한 번에 하나의 프롬프트씩 차례대로 대기합니다. 비밀번호는 시스템으로 직접 전달되며 절대 저장되거나 로그에 기록되지 않습니다.

로그인 직후 바에서 이 프롬프트를 제공할 수 없는 경우, 해당 세션 동안 KDE의 비밀번호 대화 상자가 대신 표시되어 관리자 요청이 계속 작동합니다.

## 방화벽

새로 설치한 시스템은 방화벽이 켜진 상태로 시작됩니다. 컴퓨터에서 시작한 연결에 대한 응답, 로컬 이름 검색, Eitr가 설치하는 공유 앱인 KDE Connect(포트 1714-1764) 및 LocalSend(53317)를 제외하고는 수신 연결을 거부합니다. 컴퓨터의 가상 머신과 컨테이너는 여전히 접근할 수 있으며, 발신 트래픽은 필터링되지 않습니다. SSH가 활성화되어 있으면 SSH도 계속 접근할 수 있습니다.

**설정 > 보안 > 보호 > 방화벽**에서 켜짐 여부를 확인하고 확인 후 전환할 수 있습니다. 방화벽이 도입되기 전에 설정된 컴퓨터는 꺼진 상태로 시작됩니다. 다른 앱에서 연결을 수신하도록 허용하려면 `/etc/eitr/firewall.d/`에 파일을 추가하세요. 예를 들어 다음과 같은 내용의 `game.nft` 파일을 만듭니다.

```
add rule inet eitr_firewall input udp dport 27015 accept
```

그런 다음 방화벽을 껐다가 다시 켜세요.

## 디스크 암호화 및 TPM

디스크 암호화는 설치 프로그램에서 선택하는 옵션입니다. TPM 디스크 잠금 해제는 지원되는 기존 LUKS2 루트에 TPM2 슬롯을 추가할 수 있으며, 설치 프로그램이 자동으로 등록하지는 않습니다. 암호문/복구 키는 오프라인에 보관하세요. 스크린샷이나 저장소 파일에 절대 저장하지 마세요. 펌웨어 또는 Secure Boot 변경 시 다음 부팅 때 암호문이 필요할 수 있습니다.

인증 또는 TPM 설정을 변경하기 전에 [복구 및 스냅샷](handbook:recovery)을 읽어보세요. [Secure Boot](handbook:secure-boot)는 고급 수동 프로세스입니다. EITR는 사용자를 대신하여 펌웨어 키를 등록하거나 부팅 파일에 서명하지 않습니다. 실수가 발생하면 부팅이 불가능해지거나 일부 하드웨어에서는 펌웨어 설정 화면에도 진입하지 못할 수 있습니다.

## 사용자 계정

**설정 > 사용자 > 사용자 만들기…**에서 별도의 로그인 계정을 만듭니다. 사용자 이름, 선택 사항인 전체 이름, 계정 유형 및 비밀번호를 입력한 다음, 검토하고 Enter를 눌러 생성하세요. 적용하기 전에는 Esc를 눌러 취소할 수 있습니다. 표준 계정은 sudo를 사용할 수 없으며, 관리자 계정은 wheel 그룹에 가입되고 비밀번호로 보호되는 sudo 규칙을 받습니다.

새 홈 폴더에는 기존 사용자의 계정 파일이 포함되지 않습니다. UWSM을 통해 Hyprland에 처음 로그인할 때, Eitr는 설치 프로그램의 사용자별 데스크톱 설정을 실행하고 새 사용자의 ID로 패키지 레이아웃을 채택합니다. 셸 설정에는 인터넷 연결이 필요할 수 있습니다. 설정이 실패하면 다음 로그인을 위해 보류 표시가 유지되며, 성공한 설정은 한 번만 실행됩니다. 계정 생성에 실패하면 수동 검토를 위해 불완전한 계정이 잠기고 만료 상태로 남습니다.

관리자는 설정 > 사용자에서 **사용자** 및 **관리** 탭을 볼 수 있으며, 표준 계정에는 사용자 목록만 표시됩니다. 관리자는 wheel 그룹에 속하며 Eitr sudo 규칙을 갖지만, 표준 계정은 둘 다 갖지 않습니다. 관리 탭에서는 계정 생성, 계정 유형 변경, 다른 계정의 비밀번호 설정 및 계정 제거를 수행할 수 있습니다. 각 동작마다 확인 시트가 열린 다음 작업 터미널이 열립니다. Enter를 누르면 계속되고 Esc를 누르면 취소됩니다. 비밀번호 재설정 시 터미널에서 새 비밀번호를 두 번 묻습니다. 다른 계정의 로그인 키링은 업데이트할 수 없으므로 이전 비밀번호가 유지됩니다. 본인의 계정은 사용자 탭의 비밀번호 변경을 사용하세요. 계정 제거 시 기본적으로 홈 폴더는 유지되며, 파일을 삭제하려면 홈 폴더 삭제를 선택하세요. 본인 계정, 현재 로그인 세션이 활성화된 계정, 또는 마지막 관리자는 제거할 수 없으며 마지막 관리자는 강등할 수도 없습니다. 실제 사용자 계정(UID 1000–65533)만 관리할 수 있습니다. 터미널에서 돌아오면 목록이 새로고침됩니다.

기본 그룹이 wheel인 계정은 여기서 강등할 수 없습니다. 먼저 수동 관리를 통해 기본 그룹을 변경하세요.

## 프로필 사진

설정 > 사용자에 이 PC의 모든 계정이 나열됩니다. 거기서 프로필 사진을 클릭하여 변경하거나 아래의 휴지통 아이콘을 사용하여 제거할 수 있습니다. 이미지 선택 및 자르기 조정에 대한 자세한 내용은 [설정](handbook:system)을 참조하세요. 제어 센터는 사용자의 사진만 표시합니다.
